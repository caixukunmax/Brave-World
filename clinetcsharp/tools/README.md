# Godot 自动化检测和修复工具

## 功能

自动运行 Godot 项目，检测错误，并尝试自动修复。

## 使用方法

### 方法一：双击运行（推荐）

双击 `check_and_fix.bat`，自动执行检测和修复流程。

### 方法二：命令行

```bash
# 进入工具目录
cd client/tools

# 运行检测
python auto_fix.py

# 或使用 PowerShell 仅运行 Godot 检查
powershell -File godot_runner.ps1 -Mode check
```

## 工具说明

| 文件 | 功能 |
|------|------|
| `check_and_fix.bat` | 一键运行入口 |
| `auto_fix.py` | Python 主程序，解析错误并自动修复 |
| `godot_runner.ps1` | PowerShell 脚本，启动 Godot 并捕获输出 |

## 自动修复的错误类型

- ✅ 缺失的脚本文件（自动创建空脚本）
- ✅ 未声明的变量（自动添加变量声明）
- ✅ 缺失的方法（自动添加空方法）
- ✅ Autoload 脚本缺少 extends（自动添加）
- ⚠️ 场景文件乱码（需要人工检查）
- ⚠️ 节点引用错误（需要人工检查）

## 日志位置

检测日志保存在：
- `client/.godot/auto_run_log.txt` - Godot 完整输出
- `client/.godot/auto_run_errors.txt` - 错误输出

## 工作流程

```
┌─────────────────┐
│ 运行 check_and_fix.bat
└────────┬────────┘
         ↓
┌─────────────────┐
│ 启动 Godot 检查
└────────┬────────┘
         ↓
┌─────────────────┐
│ 捕获错误日志
└────────┬────────┘
         ↓
┌─────────────────┐
│ 解析错误类型
└────────┬────────┘
         ↓
┌─────────────────┐
│ 自动修复（如果可以）
└────────┬────────┘
         ↓
┌─────────────────┐
│ 显示修复报告
└─────────────────┘
```

## 注意事项

1. 首次运行可能需要安装 Python 3.11+
2. 确保 Godot 路径正确配置（在 `godot_runner.ps1` 中修改）
3. 复杂错误仍需人工检查和修复
