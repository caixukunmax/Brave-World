# 文档目录

本目录存放项目的所有文档，按以下结构组织：

## 核心文档

| 文件 | 说明 |
|------|------|
| `需求文档.md` | 项目的核心需求文档，包含完整的功能规格和已实现功能清单 |
| `截图分析工作流.md` | F12 截图工具的使用说明和调试参数列表 |
| `调试面板说明.md` | 调试面板的完整功能说明、交互细节和冲突解决方案 |

## 开发记录

| 文件 | 说明 |
|------|------|
| `开发记录/日志系统改进方案.md` | 日志系统从"空壳"到完整 Godot 输出捕获的技术方案 |

## 文档维护原则

- **需求变动优先更新文档**：任何需求变更必须先更新本文档，再写代码
- **文档与代码保持一致**：每次功能实现后，同步更新对应文档
- **旧文档及时清理**：合并或废弃的文档应及时删除，避免信息分散
