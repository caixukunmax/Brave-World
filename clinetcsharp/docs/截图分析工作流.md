# 截图分析工作流

## 使用方法

### 1. 游戏中截图
运行游戏时，按 **F12** 键截图：
- 截图会自动保存到项目目录 `res://screenshots/`
- 同时会保存调试信息文件（`debug_info.json` + `logs.txt`）
- 屏幕会显示绿色提示确认保存成功
- 截图图片会自动复制到 Windows 剪贴板

### 2. 找到截图文件
截图保存在以下位置：

**项目目录内：**
```
res://screenshots/screenshot_YYYYMMDD_HHMMSS/
```

实际磁盘路径（Windows 示例）：
```
c:\code\我是勇者\screenshots\screenshot_20250330_192600\
```

**文件夹内包含：**
- `screenshot.png` — 游戏画面截图
- `debug_info.json` — 结构化调试信息
- `logs.txt` — 最近的游戏日志和错误信息

### 3. 发送给我分析
将截图文件直接拖拽或粘贴到对话中，我会：

1. **视觉分析** — 检查画面问题：
   - 字体显示异常（截断、模糊、对齐问题）
   - 颜色搭配问题
   - UI 布局问题
   - 视觉层次不清晰
   - 性能问题迹象（掉帧、卡顿）

2. **结合调试信息** — 分析配置是否合理：
   - 格子大小 vs 字体大小比例
   - 行间距设置
   - 边框和圆角设置
   - 相机缩放是否合适
   - 网格线宽度和亮度

3. **结合日志信息** — 检查是否有报错或异常输出

4. **给出优化建议** — 提供具体的参数调整建议

## 分析示例

### 示例 1：字体显示问题
**你发送：** [截图显示文字被截断]

**我分析：**
```
观察到的问题：
- 第3行文字"普通人"底部被截断
- 当前格子大小：111px，字体大小：自动计算约22px
- 行间距：0.8（较小）

建议调整：
1. 增加行间距到 1.0 或 1.2
2. 或减小字体大小到 18px
3. 或增加格子大小到 128px
```

### 示例 2：视觉层次问题
**你发送：** [截图显示界面元素拥挤]

**我分析：**
```
观察到的问题：
- 网格线太粗太亮，与玩家边框竞争视觉焦点
- 相机缩放 1.4x 下格子边缘有些模糊

建议调整：
1. 降低网格线亮度到 0.4-0.5
2. 减小网格线粗细到 0.5
3. 尝试相机缩放 1.0x 或 2.0x（避免非整数缩放导致的模糊）
```

## 当前支持的调试参数

截图时自动收集的信息：
- **玩家状态**: 位置、网格位置、格子大小、边框宽度、圆角半径、字体大小、行间距
- **相机设置**: 缩放级别、位置、平滑速度
- **网格设置**: 格子大小、地图尺寸、线宽、颜色、编辑模式、视野内绘制格子数、总格子数
- **日志信息**: 最近 10 条日志和错误日志（通过 LogCollector 收集所有 Godot 输出）

这些信息帮助我准确分析问题根源。
