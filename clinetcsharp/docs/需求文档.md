# 需求文档

## 概述

一个简洁的网格地图探索游戏，玩家控制一个带有4行角色信息的面板在黑色背景的虚线网格中移动。

---

## 核心玩法

### 1. 开局流程
- 游戏启动后直接加载进入地图场景
- 无需主菜单或开场动画

### 2. 地图设计

#### 网格系统
- 地图由格子形状组成
- 背景颜色：**纯黑色**
- 网格线样式：**虚线**交织组成网格
- 网格线颜色：建议使用浅灰色或白色（与黑色背景形成对比）

#### 网格规格
- 格子大小：111x111 像素（默认，可调范围 32~256）
- 地图尺寸：50x50 格
- 支持**响应式布局**：根据屏幕大小自动调整格子尺寸，保持固定横向格子数

### 3. 角色显示系统（通用设计）

每个角色（玩家、敌人、NPC等）以正方形格子展示，内部包含4行文字信息：

#### 显示内容（4行）
| 行数 | 内容 | 示例 | 说明 |
|------|------|------|------|
| 第1行 | 等级 + 角色名 | `Lv.1 王建国` | 固定格式 |
| 第2行 | 职业 | `农夫` | 职业类型 |
| 第3行 | 称号 | `普通人` | 称号/段位 |
| 第4行 | 当前状态 | `闲逛中...` | 动态行为描述 |

#### 外观规格
- 形状：**正方形**
- 大小：**只占一个格子**，自适应文字内容
- 边框线条：**可调粗细**（默认比网格线粗）
- 边框颜色：亮色（默认白色）
- 填充颜色：可调透明度（默认10%白色）
- 圆角半径：**可调**（0-30像素）
- 文字对齐：**可调**（居中/左对齐/右对齐）

#### 文字自适应规则
1. **优先缩小字号**：确保4行文字能在格子内显示
2. **最小字号限制**：达到最小字号后，自动放大格子
3. **调试面板限制**：格子大小不能缩小到比文字还小
4. **支持自动/手动字号切换**：通过明确的"自动字号"开关控制

### 4. 玩家角色

#### 移动机制
- 移动方式：**格子间移动**（从一个格子移动到相邻格子）
- 控制方式：键盘方向键 / WASD
- **过渡效果**：移动时需要有平滑的过渡动画（Tween 插值移动）

#### 相机控制
- **跟随模式**：相机默认平滑跟随玩家
- **拖拽视角**：可用鼠标按键自由拖拽视角（按键可在调试面板设置）
  - 拖拽期间相机**不跟随**玩家
  - 松开鼠标后，延迟一段时间（默认0.5秒，可调0-3秒）恢复跟随
  - 恢复过程支持缓动曲线设置（线性/平滑/缓入/缓出/缓入缓出）
- **自由视角模式**：开启后可用滚轮缩放+拖拽自由移动相机，用于观察和编辑

#### 默认显示内容
```
Lv.1 王建国
农夫
普通人
闲逛中...
```

### 5. 调试面板功能

右上角圆形按钮展开调试面板，包含以下调节项：

| 调节项 | 范围 | 说明 |
|--------|------|------|
| **地图** |||
| 格子大小 | 32-256 | 地图和角色格子同步调整 |
| 视角远近 | 0.5x-3.0x | 相机缩放 |
| 网格线粗细 | 0.5-5.0 | 虚线网格线宽度 |
| 网格线明暗 | 0.1-1.0 | 网格线颜色亮度 |
| 网格线最大宽度 | 0.5-10.0 | 自适应模式下的上限值 |
| 显示坐标 | 开关 | 在每个格子上显示 x,y 坐标 |
| 线宽自适应校准 | 开关 | 根据相机 zoom 自动计算线宽，支持双参考点校准 |
| 响应式布局 | 开关 | 根据屏幕大小自动调整格子尺寸 |
| 横向格子数 | 1.0-30.0 | 响应式布局下屏幕横向显示的格子数量（支持小数） |
| **相机** |||
| 自由视角 | 开关 | 开启后可用鼠标拖拽自由移动相机 |
| 拖动视野按键 | 左/右/中键 | 设置拖拽相机使用的鼠标按键 |
| 返回延迟 | 0-3.0秒 | 拖拽视角后恢复跟随的延迟 |
| 返回速度 | 1-20 | 镜头回到玩家身上的移动速度 |
| 缓动类型 | 下拉选择 | 线性/平滑/缓入/缓出/缓入缓出 |
| 缓动强度 | 1.0-5.0 | 缓动效果的强度 |
| **玩家** |||
| 角色大小 | 32-256 | 视觉大小（独立于网格大小） |
| 边框粗细 | 1-10 | 角色边框线宽 |
| 圆角半径 | 0-30 | 角色方块四角弧度 |
| 背景明度 | 0.0-1.0 | 内部背景透明度（0=透明，1=纯白） |
| 字体选择 | 下拉+文件 | 内置字体或加载自定义字体 |
| 自动字号 | 开关 | 开启时自动根据玩家大小计算字号 |
| 字体大小 | 0-48 | 手动模式下的字号（0在旧版中表示自动，新版有独立开关） |
| 行间距 | 0.5-1.5 | 4行文字间距系数 |
| 字间距 | -5~10 | 文字字符间距 |
| 对齐方式 | 左/中/右 | 4行文字的对齐方式 |
| 台词颜色 | 6种预设 | 每行独立颜色（点击切换） |
| 粗体/斜体/阴影 | 开关 | 文字样式效果 |
| **编辑器** |||
| Ctrl+点击选中 | 开关 | 地图编辑模式下是否需要按住Ctrl才能框选格子 |
| **操作** |||
| 保存配置 | 按钮 | 永久保存当前设置 |
| 放弃修改 | 按钮 | 恢复到最后保存的状态 |
| 保存预设 / 加载预设 | 按钮 | 保存或加载多组配置方案 |

#### 面板特性
- 支持滚动：内容超出时自动出现滚动条
- 自适应高度：根据屏幕高度自动调整（最大70%）
- 配置持久化：设置保存到 `user://debug_panel_config.cfg`
- 预设持久化：预设保存到 `user://debug_panel_presets.cfg`
- 启动恢复：下次启动自动加载保存的设置

### 6. 地图编辑器

按 **E 键** 切换地图编辑模式：
- **框选格子**：鼠标拖拽框选多个格子（可设置是否需要按住 Ctrl）
- **设置属性**：对选中格子应用存在性/可行走性/可见性/地形类型
- **删除格子**：按 Delete 键删除选中的格子
- **撤销操作**：Ctrl+Z 撤销上一步编辑操作
- **全选**：Ctrl+A 选中所有格子
- **保存地图**：编辑后的地图数据自动保存到 CSV
- **导入/导出**：支持从外部 CSV 导入或导出地图数据

### 7. 截图与日志工具

按 **F12** 一键截图：
- 截图保存到项目目录 `res://screenshots/screenshot_YYYYMMDD_HHMMSS/`
- 同时保存 `debug_info.json`（结构化调试信息）和 `logs.txt`（最近日志）
- 截图自动复制到 Windows 剪贴板
- 屏幕显示绿色保存提示

日志系统通过 `LogCollector` Autoload 收集所有 Godot 输出（`print()`、`push_error()`、引擎报错）。

## 视觉层次
```
第1层（最底层）: 黑色背景
第2层         : 虚线网格（细线）
第3层（最上层）: 角色格子（可调粗细边框 + 4行文字）
```

---

## 技术实现要点
- 使用 Godot 4.6.1 开发
- 网格：自定义 Node2D + _draw() 绘制虚线
- 角色：Node2D + RichTextLabel 节点显示4行文字
- 移动过渡：Tween 动画实现平滑移动
- 文字自适应：动态计算字号或格子大小
- 调试面板：CanvasLayer + 滑块控制
- 地图数据：CSV 格式存储，支持导入导出
- 日志收集：读取 Godot 文件日志 `user://logs/godot.log`
