# 调试面板说明

调试面板是游戏中的客户端配置与调试界面，现已接入共享的可拖拽面板框架，支持拖拽、缩放、最小化、关闭，本地配置保存在客户端用户目录。

---

## 界面布局

- **打开方式**：`F12` 或功能按钮栏中的“调试面板”按钮
- **标题栏**：支持拖拽、最小化、关闭
- **标签页切换**：地图 / 玩家 / 怪物 / NPC / 系统 / UI
- **分组折叠**：每个分组可独立展开/收起
- **底部按钮**：保存配置 / 放弃修改 / 保存预设 / 加载预设

---

## 当前标签页概览

- **地图**：网格、相机、校准、响应式布局、编辑器键位
- **玩家**：外观、文字、标签、血条、施法条、动作栏、等级徽章
- **怪物**：怪物显示、标签和 AI 调试项
- **NPC**：NPC 显示与标签调试项
- **系统**：移动系统与相关运行参数
- **UI**：技能栏等界面调试项

## 地图标签页

### 基础设置
| 功能 | 说明 |
|-----|------|
| 格子大小 | 调整地图格子像素尺寸 (32~256) |
| 视野 | 相机缩放比例 (0.5~3.0) |

### 网格线设置
| 功能 | 说明 |
|-----|------|
| 网格线粗细 | 手动模式：设置线宽；校准模式：预览线宽 |
| 网格线亮度 | 线条颜色明暗 (0.1~1.0) |
| 网格线最大宽度 | 自适应模式下的上限值 (0.5~10.0) |
| 显示坐标 | 在每个格子上显示 x,y 坐标 |
| **线宽自适应校准** | 开关模式，开启后根据相机 zoom 自动计算线宽 |
| **响应式布局** | 根据屏幕大小自动调整格子尺寸 |
| 横向格子数 | 响应式布局下屏幕横向显示的格子数量 (1.0~30.0，支持小数) |

### 相机设置
| 功能 | 说明 |
|-----|------|
| 自由视角 | 开启后可用鼠标拖拽移动相机 |
| 拖动视野按键 | 设置拖拽相机使用的鼠标按键（左/右/中键） |
| 返回延迟 | 停止操作后多久相机开始跟随玩家 (0~3.0秒) |
| 返回速度 | 相机跟随玩家的移动速度 (1~20) |
| 缓动类型 | 线性/平滑/缓入/缓出/缓入缓出 |
| 缓动强度 | 缓动效果的强度 (1.0~5.0) |

### 调试开关
| 功能 | 说明 |
|-----|------|
| 显示调试信息 | 在玩家头顶显示坐标等调试信息 |
| 相机调试 | 显示相机状态和边界框 |

## 高级功能

### 线宽自适应校准
根据相机缩放自动调整网格线宽度，确保不同缩放下线宽视觉一致。

**参考点设置**：
- 参考点A：低 zoom（视野拉远），线宽较大
- 参考点B：高 zoom（视野拉近），线宽较小

**使用方式**：
1. 开启"启用自适应校准"
2. 设置两个参考点的视野值和期望线宽
3. 拖动相机观察线宽自动变化
4. 网格线粗细滑块变为预览模式：拖动预览不同线宽，松手恢复

### 响应式布局
根据屏幕尺寸自动计算格子大小，确保始终显示固定数量的格子。

**参数**：
- 横向格子数：屏幕宽度显示的格子数量（支持小数如 5.5）

### 自由视角
开启后可使用鼠标拖拽自由移动相机，用于地图编辑和观察。

## 配置保存

- **配置路径**：`user://debug_panel_config.cfg`
- **预设路径**：`user://debug_panel_presets.cfg`
- **面板几何自动保存**：拖拽或缩放结束后自动保存面板位置和大小
- **参数保存**：点击"保存配置"按钮
- **配置内容**：所有滑块值、开关状态、颜色选择、字体路径
- **恢复默认**：点击"放弃修改"恢复到最后保存的状态

## 交互细节

### 滑块交互
- **拖动时**：实时更新数值显示
- **松手后**：才实际应用到游戏（避免频繁更新）
- **例外**：线宽在校准模式下拖动时实时预览

### 输入拦截
- 鼠标在面板内时，滚轮和点击不会影响到游戏
- 自由视角模式下相机操作不受影响

### 同步机制
- 格子大小与玩家大小联动
- 网格线粗细与最大宽度联动

## 功能冲突与解决方案

### 冲突 1：线宽校准 vs 网格线粗细滑块 ✅ 已解决
- **冲突**：校准开启时，滑块值与自适应计算值矛盾
- **解决**：校准开启时滑块变为预览模式，拖动预览，松手恢复

### 冲突 2：线宽校准 vs 最大宽度滑块 ✅ 已解决
- **冲突**：校准值可能被 line_width_scale 限制
- **解决**：校准模式下禁用最大宽度滑块（`editable = false`），由算法控制

### 冲突 3：响应式布局 vs 线宽自适应校准 ✅ 已解决
- **冲突**：响应式布局会自动调整相机 zoom，线宽校准基于 zoom 计算，可能产生预期外结果
- **解决**：
  - 响应式布局开启时，自动禁用线宽校准（如果已开启则自动关闭）
  - 线宽校准开关变为不可操作状态（`disabled = true`）
  - 显示提示："响应式布局开启时不可使用线宽校准"

### 冲突 4：响应式布局 vs 格子大小滑块 ✅ 已解决
- **冲突**：响应式布局自动控制格子大小，与手动滑块矛盾
- **解决**：响应式开启时禁用格子大小滑块（`editable = false`），数值旁显示"(自动)"

### 冲突 5：自由视角 vs 视野滑块 ✅ 已解决
- **冲突**：自由视角模式下可用滚轮缩放视野，滑块值实时变化可能让用户困惑
- **解决**：自由视角开启时禁用视野滑块（`editable = false`），仅作为只读显示

### 冲突 6：自由视角 vs 相机返回设置 ✅ 已解决
- **冲突**：自由视角模式下相机不跟随玩家，但"返回延迟"和"返回速度"设置仍然存在
- **解决**：自由视角开启时禁用返回延迟、返回速度、缓动类型、缓动强度设置，标签显示"自由视角"

### 冲突 7：字体大小自动 vs 手动 ✅ 已解决
- **冲突**：旧版用 0 值表示"自动"，逻辑较隐晦
- **解决**：添加了明确的"自动字号"开关（`font_auto_size_check`），与字体大小滑块分离
