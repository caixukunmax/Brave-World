# 2026-07-09 工作日志

## 全项目代码审查（优化点排查）

对 tslua2 项目（Godot 客户端 + C# 服务端 MMORPG）做了三维度优化审查：服务端、客户端、工程化。共发现 17 个值得优化的点，已用「工作量×收益」优先级矩阵呈现给用户。

### 最关键发现（高优先级）

**服务端并发正确性**
- `Program.cs:324-374` PlayerAutoSaveLoop 在独立 PeriodicTimer 线程直接读写 Role 字段（Hp/GridX/MoveSpeedMs）写 MongoDB，未通过 IGameLoopScheduler 入队，与 GameLoop 线程并发修改这些字段，违反 AGENTS.md 单线程约束。这是真实的共享状态竞争。
- `EnterGameHandler.cs:150` EquippedSkills 直接引用赋值，而 ChangeMapHandler/DeathResponder 都 new List 复制，三处不一致，登录后共享引用可能导致不同步。
- `MapPlayerState.PreferredSkillId` 在 PlayerSnapshot 无对应字段，PlayerEnter 未设置，登录/切图/重生后丢失为 0（AGENTS.md 第74行担忧的"新增字段同步遗漏"真实发生）。

**服务端热路径性能**
- `CombatTrace.cs` 十余个方法（DamageApply/DamageCalc/BuffTick/BuffApply/HealApply/SkillStartCast）全部 LogInformation，在 100ms 战斗 tick 热路径刷屏，违反 AGENTS.md 第73行。应统一降 LogDebug。
- `CombatManager.cs` 1656 行 God Object，承担碰撞/伤害/治疗/buff/回复/广播全职责，应拆分。
- `MapService.cs:205-228` RefreshCombatPositionsForSnapshot 每 100ms 全量 LINQ ToList 分配。

**客户端**
- `screenshots/` 307 个 png + 306 import（23MB），169 个被 git 跟踪。ScreenshotTool.cs:97 存到 res:// 触发 Godot 生成 .import。应改存 user:// + gitignore + git rm --cached。
- 残留违规 shader：grid_overlay_test6.gdshader:36 / test6a.gdshader:35 的 fragment() 含 return，违反 AGENTS.md 铁律（虽未引用但易误用）。grid_overlay.gdshader.bak 应删。
- `MapEditor.cs` 2819 行超大类，3 处 new CanvasLayer，应拆分。

**工程化**
- `protocols/include/include/google/protobuf/` 是误嵌套重复拷贝（16 文件），应删。
- `package.json` 的 @ai-sdk/openai-compatible 是死依赖，无任何引用。
- `新建 文本文档.txt` 实为有价值的优化清单，但 .gitignore 规则写的是"新建文本文档.txt"（无空格）与实际"新建 文本文档.txt"（有空格）不匹配，规则失效且文件已入库。
- Luban 的 .sbn/.dll/.exe、protoc.exe 等构建产物入库，应改 dotnet tool / submodule。
- Directory.Build.props 长期 NoWarn CA1304/1305/1311/1862（CultureInfo 相关），应分批解除而非压制。
- 测试缺口：所有 Player Handler、MonsterManager/CombatManager.Tick、DeathResponder 零测试。
