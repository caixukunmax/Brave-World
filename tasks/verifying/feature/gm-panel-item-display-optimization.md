# GM面板道具栏显示优化

## 现象
道具分组有6个按钮，HFlowContainer换行到第二行时被底部"添加分组"工具栏遮挡，用户看不到/点不到被挡住的按钮。

## 根因
1. `_groupScroll.CustomMinimumSize.Y = 80` 太小，内容超出可见区
2. 分组不可折叠，所有分组的按钮同时展开占用大量垂直空间
3. 工具栏在滚动区外部固定，与滚动内容争抢空间

## 修复方案（B + C 组合）

### Step 1: 修复滚动区高度（B）
- 去掉 `_groupScroll.CustomMinimumSize.Y = 80`，让滚动区自适应内容
- 面板 `MinHeight` 从 150 → 300，确保默认能容纳所有分组
- 确保滚动条在内容超出时自动出现

### Step 2: 分组可折叠（C）
- 每个分组的 header 行加折叠/展开按钮（▶/▼）
- 默认只展开第一个分组，其余折叠
- 折叠时只显示标题行，不显示命令按钮流
- 折叠状态保存在 GmGroup 数据中，RebuildGroupUI 时读取

## 影响范围
- `clinetcsharp/Scripts/GMPanel.cs` — 唯一修改文件
- 不影响服务端、协议、配置表

## 验证方式
1. 打开GM面板，道具分组默认展开，6个按钮完整显示不被遮挡
2. 其他分组默认折叠，只显示标题行
3. 点击折叠按钮可展开/收起分组
4. 添加新分组后默认折叠
5. 面板可正常 resize，滚动区自适应
