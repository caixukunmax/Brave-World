## 描述

修复服务端5个高危安全问题，全部影响上线安全性。

## 问题清单

| # | 问题 | 影响 | 文件位置 |
|---|---|---|---|
| 1 | TokenSecret 硬编码在 appsettings.json 且已提交到 Git | 任何人可伪造 GatewayToken | `appsettings.json` |
| 2 | MD5 密码哈希（PasswordHasher） | 彩虹表秒破解 | `PasswordHasher.cs` |
| 3 | MD5 Token 签名（TokenGenerator） | 长度扩展攻击可伪造 Token | `TokenGenerator.cs` |
| 4 | GatewayToken 7天不过期 | 被盗后7天内有效 | `TokenGenerator.cs` |
| 5 | 自动注册无验证 | 批量刷号、机器人注册 | `LoginService.cs` |

## 修复方案

### #1 TokenSecret 硬编码
- `git rm --cached appsettings.json`
- 创建 `appsettings.Example.json`（模板，不含真实密钥）
- `.gitignore` 排除 `appsettings.json` 和含密钥文件
- 运行时从环境变量 `TSLUA2_TOKEN_SECRET` 读取，fallback 到 UserSecrets

### #2 MD5 密码哈希 → bcrypt
- 引入 `BCrypt.Net-Next` NuGet 包
- `PasswordHasher` 改为 `BCrypt.HashPassword(password, workFactor: 11)`
- `VerifyPassword` 改为 `BCrypt.Verify(password, hash)`
- 向后兼容：检测旧 MD5 格式（含冒号分隔符），登录时自动迁移到 bcrypt

### #3 MD5 Token 签名 → HMAC-SHA256
- `TokenGenerator` 改用 `HMACSHA256` 替代 `MD5.Create()`
- AccountToken/GatewayToken 签名全部改 HMAC-SHA256
- 取消 CA5351 抑制

### #4 GatewayToken TTL 7天 → 2小时
- `GatewayTokenExpiryHours` 从 168 改 2
- 可选：加刷新机制（refresh token），当前先缩短 TTL

### #5 自动注册无验证 → 加开关
- `appsettings.json` 新增 `AllowAutoRegister: false`（默认关闭）
- `LoginService` 读取配置，为 false 时返回"账号不存在，请联系管理员"
- 开发环境可手动开启
