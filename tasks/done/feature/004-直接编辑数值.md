## 描述

点击比例类数值标签弹出输入框，允许直接输入精确数值。

## 2026-05-06 修复

### Bug 1: 输入值后没能正确保存
- **根因**: `FocusExited` 和 `_Input` 的点击外部处理双重触发 `ApplyValue`
- 第一次 `_Input` 执行 `ApplyValue` → `applying = false` → `edit = null`
- 第二次 `FocusExited` 执行 `ApplyValue` → `applying` 已重置为 false → 再次执行 → 访问 `edit.Text` 时 NRE
- **修复**: `FocusExited` 回调中先检查 `edit == null`，如果 `_Input` 已经 Apply 过则跳过

### Bug 2: 点击其他位置没有取消输入状态
- **根因**: `SliderValueInput.HandleUnhandledInput` 在 `_UnhandledInput` 中调用
- `_UnhandledInput` 只在输入未被处理时触发，点击 DebugPanel 内部的控件通常被 `_Input` 消耗
- 点击不可聚焦控件（如 Label）时，`FocusExited` 不触发，`_UnhandledInput` 也到不了
- **修复**: 将点击外部检测从 `_UnhandledInput` 移到 `_Input`，使用 `GetGlobalRect().HasPoint()` 判断点击是否在 LineEdit 内部

### 修改文件
1. `SliderValueInput.cs` — 新增 `HandleInput` 方法（检查点击位置），`FocusExited` 加 `edit == null` 保护
2. `DebugPanelTab.cs` — `AttachValueLineEdit` 的 `FocusExited` 加 `edit == null` 保护
3. `DebugPanel.cs` — `_Input` 中调用 `SliderValueInput.HandleInput`，`_UnhandledInput` 中移除旧调用
