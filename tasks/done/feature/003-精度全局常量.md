## 描述

比例类参数（Scale/Opacity/亮度/倍率等）的 Step 和显示格式统一收口到一个常量文件，改一处全局生效。

## 当前问题

- Step 硬编码：0.01 / 0.05 / 0.1，散落各处
- 显示格式硬编码：ToString("F2")，只显示两位小数
- 目标：统一到 0.001（三位小数）

## 方案

在 DebugPanelLengthScalePolicy.cs 中定义：
- `Step = 0.001` — 滑条步长
- `StepF = 0.001f` — float 版（CreateSliderRow 参数用）
- `FormatStr = "F3"` — 显示格式

所有比例类滑条和 ToString 引用这三个常量，零硬编码。

## 验证

- 编译 0 错误
- 所有比例类滑条支持三位小数调节和显示
- 改常量文件一处即可全局生效
