# 地图编辑器网格整图渲染修复

> 状态：已确认，可实施
> 日期：2026-05-20

## 1. 问题描述

当前地图编辑器在改变视野距离后，会出现部分网格线看不见的问题。症状并不稳定：

- 同一组参数在不同缩放级别下，部分横线或竖线会丢失。
- 相机拖动后，丢失的线有时会重新出现。
- 相机控制器已经出现“限制最小缩放，防止网格线渲染异常”的补丁式注释，说明问题不是孤立参数错误，而是当前渲染结构本身不稳定。

## 2. 根因

当前实现把整张地图的每一条网格线都建成超长 `Line2D` 节点，并在相机缩放、平移、参数变化时动态修改：

- `Line2D.Points`
- `Line2D.Width`
- 视口 2D 像素对齐设置

这个方案的根本问题是：

1. 线宽是屏幕像素语义，但几何是世界坐标语义。
2. 单条线跨越整张地图，渲染稳定性依赖 Godot 的 `Line2D` 裁剪、栅格化和相机变换组合结果。
3. 缩放和平移后，某些线会在裁剪边界或像素量化过程中表现为丢失、忽粗忽细或需要重新刷几何才能恢复。

因此，问题根源不是“线宽参数不对”，而是“渲染原语和绘制范围设计错误”。

在 shader 版本中，还需要额外处理一个 GPU 采样问题：

4. 如果只用“距离网格线小于阈值就画，否则不画”的硬切换，在远视野下世界网格投影到屏幕后会进入子像素采样区间。
5. 这时不是随机缺线，而是会按照固定屏幕采样节奏出现规则性漏线或明暗不均，本质上是混叠，不是数据缺失。

## 3. 目标

- 缩放和平移时，网格线持续可见，不再依赖限制 `zoom` 来回避异常。
- 保留现有线宽自适应、亮度、编辑模式白线等调试面板能力。
- 保留一个可现场调参的抗锯齿柔化强度入口，方便在不同分辨率/缩放档位下快速校准观感。
- 网格应按整张地图稳定绘制，而不是只在局部视口范围内出现。
- 修复后地图在远视野下仍应保持“整图有网格”的视觉预期。

## 4. 方案选择

### 4.1 不采用的方案

#### A. 继续在 `Line2D` 上打补丁

包括但不限于：

- 继续限制最小/最大 `zoom`
- 继续抬高最小线宽
- 继续在相机位置变化时反复重建 `Line2D`
- 继续调像素对齐开关

这类方案只能把异常推迟到另一段缩放区间，不能根治。

#### B. 继续沿用世界空间多矩形/多边界绘制

这条路线已经试过两次：

- 先试了按视口局部线段绘制
- 再试了整图连续横竖 `DrawRect`

两次都能改善问题，但仍会在某些缩放/相机位置下出现残余缺线，说明根因仍然在世界空间几何绘制和像素栅格化耦合上。

### 4.2 采用的方案

采用“shader overlay + 单个地图底板”替代“全图 `Line2D` 节点数组”和“世界空间大量 `DrawRect`”：

1. `GridManager` 只维护一个覆盖整张地图的 shader 底板。
2. shader 以地图底板自身的本地坐标为基准计算世界格子位置，让网格和地面一起受相机缩放，不把网格当成屏幕覆盖层。
3. 基础网格与格子 `Exists` 状态解耦，整张地图范围内始终有连续网格。
4. 删除格子继续走半透明填充逻辑，但不再决定基础网格是否存在。
5. 相机缩放、平移、视口大小变化时，只更新 shader 的显示参数，不再重建大量世界空间线几何。
6. shader 不能只用硬阈值判断是否命中网格线，必须结合屏幕导数做抗锯齿覆盖计算，避免远视野下出现规则性漏线。

## 5. 代码结构

### 5.1 `GridManager` / `GridShaderOverlay` 改造

- 删除 `Line2D` 节点数组及其初始化逻辑
- 新增 `GridShaderOverlay`，作为 `GridManager` 的子节点承载 shader 底板
- `_Process()` 在相机缩放、平移、线宽参数变化时更新 shader uniform
- `_Draw()` 只保留删除格子填充、调试覆盖和文字层
- 保留现有 `ComputeGridLineRenderStyle()`，继续作为线宽与颜色的唯一计算入口
- 新增可配置的抗锯齿柔化强度参数，并通过调试面板传入 shader uniform
- 地图编辑器右侧诊断文本显示当前抗锯齿柔化强度，方便现场确认当前生效参数
- 不再让 `Exists` 状态决定基础网格是否存在

## 6. 非目标

本次修复不处理以下范围：

- 不把网格改成 shader 驱动
- 不额外重构调试面板布局
- 不顺手修改地图编辑器其他交互逻辑
- 不改变现有配置字段结构

### 7.2 运行时验证

使用现有自动截图链路，覆盖以下 `zoom`：

- `1.0`
- `0.7`
- `0.5`
- `0.4`
- `0.3`
- `0.2`

确认各档位下：

- 网格仍然覆盖整张地图的可见区域，而不是只在局部出现
- 不再出现部分网格线消失
- 线宽变化连续
- 相机拖动后线条不闪烁、不丢失
