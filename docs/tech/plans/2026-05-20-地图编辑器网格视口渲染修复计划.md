# 地图编辑器网格整图渲染修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 shader overlay 替换全图 `Line2D` 与世界空间多矩形网格渲染，消除缩放与平移下的残余缺线问题并保持整张地图网格可见。

**Architecture:** `GridManager` 新增一个 `GridShaderOverlay` 子节点，使用单个 shader 底板按地图本地坐标绘制网格，不再维护 `Line2D` 子节点，也不再依赖世界空间大量 `DrawRect`。线宽和颜色仍复用现有策略逻辑，删除格子填充与编辑叠层继续由 `GridManager._Draw()` 负责。

**Tech Stack:** Godot 4.6 C#, xUnit, existing MapEditor auto-screenshot flow
