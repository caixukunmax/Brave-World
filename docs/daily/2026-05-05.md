# tslua2 日报 2026-05-05

## Buff 系统统一 + 完整功能补全

### 改动总览

**1. BuffContainer/BuffInstance 移到 Common 层**
- `GameServer.Common.Buffs` 命名空间，Services 和 GameLogic 都能用
- MapPlayerState.Buffs = BuffContainer（替代 GmBuffs/GmBuffEntry）

**2. 战斗/非战斗 Buff 统一**
- MapPlayerState.Buffs 是唯一容器
- 战斗时 CombatContext.Buffs 共享引用（FindPlayerBuffs）
- 怪物没有 MapPlayerState，战斗时创建独立 BuffContainer

**3. Buff 配置表新增 clear_on_disengage**
- `__beans__.xlsx` 加字段定义（bool 类型）
- `#Buff-Buff表.xlsx` 加数据列
- 脱战时 ClearOnDisengage() 只清 clear_on_disengage=true 的 buff

**4. Buff 过期自动移除**
- CombatManager.TickBuffs() 每帧检查 ExpireTime
- 过期 → RemoveBuff + 推送 BuffUpdateNotify

**5. DOT tick**
- TickBuffs 检查 tick_interval > 0 且 tags 含 "dot" 的 buff
- 按 interval 执行 OnTick 效果（伤害 = SnapshotAtk × coefficient）
- 调用 ApplyDamage 应用伤害

**6. 技能加 buff 推送 BuffUpdateNotify**
- TickBuffs 用 _lastBuffCount 跟踪每帧 buff 数量变化
- 数量变了（技能新增/过期移除）→ 推送 BuffUpdateNotify

**7. 属性修正实时生效**
- DealDamageAction.CalcDamage 加 GetBuffAttrModifier
- patk/pdef/matk/mdef 都加上 buff 修正值

**8. 护盾吸收**
- ApplyDamage 扣血前调用 p.Buffs.AbsorbShield(damage)
- absorbed 部分不扣血，剩余部分才扣

**9. ApplyBuffAction 修复**
- ExpireTime 根据配置表 duration 计算（不再硬编码 0）
- ShieldRemaining 优先用参数，fallback 到配置表 shield_base
- 注入 LubanTableLoader

**10. GM addbuff 修复**
- ExpireTime 也根据配置表 duration 计算
- ShieldRemaining 用配置表 shield_base

**11. LubanTableLoader 注册 DI**
- Program.cs 注册单例
- MapService/HotReloder/GameLogicFactory 统一注入
- GameLogicFactory 不再自己创建 LubanTableLoader

**12. 脱战清 buff**
- CombatManager 脱战时调用 p.Buffs.ClearOnDisengage()
- 推送剩余 buff 列表（非空）给客户端

### 经验教训
- 不要为"临时方案"建特殊类型——GmBuffEntry 就是为了绕开依赖问题建的，结果变成两套系统
- DI 注册要完整——LubanTableLoader 一直在 GameLogicFactory 里手动创建，没注册 DI
- 热更新传参要同步——GameLogicFactory 构造函数变了但 HotReloder 的 Activator.CreateInstance 没跟上
- Luban xlsx 的 ##type 行必须填类型名（bool），不能填值（true）

## 技能+Buff 体系扩展

### 问题
- SkillPipeline 的 action_type 映射只有 1/2/3，缺少 4=ApplyBuff 和 5=ApplyShield，导致技能 20-27 的 buff 效果从未执行
- 冰霜新星(6) 只有伤害没有减速 debuff
- 石肤术(21) 和祝福(25) 的 buff_id 指向错误
- ApplyBuffAction 的 ActionType 是 "apply_buff" 但注册名是 "ApplyBuff"，不匹配
- DOT 伤害统一用 SnapshotAtk，但灼烧是魔法 DOT 应该用 SnapshotMatk
- 减速 debuff 修改 agility 属性但 GetAgilityCoefficient 不读 buff 修正
- 护盾消耗不触发推送
- 客户端脱战时 ClearAll 导致闪烁

### 修复

**Bug 21：SkillPipeline 缺少 action_type 4/5/6 映射**
- 加 4→"ApplyBuff", 5→"ApplyBuff"(复用), 6→"Purify"
- ActionParams 加 buff_id 字段

**Bug 22：ApplyBuffAction ActionType 不匹配**
- "apply_buff" → "ApplyBuff"

**Bug 23：技能配置修正**
- 盾击(3): 加眩晕 buff(10)
- 冰霜新星(6): 加减速 debuff(6)
- 石肤术(21): buff_id 改为 5(石肤)
- 祝福(25): buff_id 改为 8(祝福)
- 野性突击(14): 加眩晕 buff(10)

**Bug 24：DOT 伤害类型区分**
- BuffInstance 加 SnapshotMatk 字段
- ApplyBuffAction 创建时快照 patk 和 matk
- TickBuffs 根据 effect.DamageType 选择 SnapshotAtk/SnapshotMatk
- DOT damageType 也从配置表读取（不再硬编码 "magic"）

**Bug 25：减速 debuff 不影响 ATB**
- GetAgilityCoefficient 改为实例方法，读 p.Buffs.GetAttrModifier("agility")
- 怪物从 CombatContext.Buffs 读取

**Bug 26：护盾消耗不触发推送**
- TickBuffs 加 _lastShieldAmount 跟踪
- 护盾总量变化时也推送 BuffUpdateNotify

**Bug 27：客户端脱战闪烁**
- OnCombatStateNotify 不在战斗中时不再 ClearAll，让 BuffUpdateNotify 决定

- 4 个标签行全部展开，占用大量空间
- 每个标签的名称/内容/字号/偏移等设置全部平铺显示

### 修复1：标签组件 CollapsibleContainer 重构
- 每个标签行用 CollapsibleContainer 包裹，默认折叠
- 标题行：▶ 标签名 + 名称输入框 + 内容输入框 + 可见性开关 + 颜色按钮 + 重置按钮

### 问题3：组件 × 按钮容易误触

### 修复3：管理组件对话框
- 去掉每个组件标题行的 × 按钮

### 问题4：ApplyProfile 覆盖 Monster 运行时标签文字
- Monster.Setup() 设了名称/等级/属性标签
- ApplyProfile 用空的 ContentPreview 覆盖，标签全部消失

### 修复4：ContentPreview 空值检查
- 恢复 !string.IsNullOrEmpty 检查，Profile 只在有值时覆盖标签内容
- Profile 只控制样式（字号/偏移/颜色/可见性），不覆盖运行时内容

### 问题5：SyncFromEntity 可见性硬编码

### 执行过程中的问题分析

**问题A：正则替换破坏文件编码**
- 用 PowerShell 的 `-replace` 正则删除 `RefreshAddComponentOption();` 调用
- 正则匹配了字符串内部的换行（如 `"新配置"` 里的中文字符被截断）
- 导致多处中文注释变成乱码，注释和代码合并在同一行
- **教训**：不要用正则全局替换处理 C# 源文件，特别是包含中文的文件。应该用 edit 工具逐个精确替换

**问题B：修复乱码的连锁反应**
- 修了一处乱码，编译发现还有更多处
- 反复修了 5-6 次才全部清理干净
- **教训**：正则破坏后应该一次性扫描所有损坏位置，而不是修一个编译一次

**问题C：write 工具文件太长被截断**
- 尝试用 write 工具重写整个文件，但文件太长被截断
- **教训**：大文件重写应该用 exec + node/python 写入，或者用 edit 逐段修复
