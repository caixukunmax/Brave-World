# 2026-07-01 角色 UI 碎碎念

## 角色 UI 设计思路

- **执行状态 + 进度叠加**
  - 用**浅色遮罩**表示当前动作的进度（如施法、蓄力、普攻冷却等）。
  - 遮罩覆盖在角色头像/立绘上，进度从 0% → 100% 逐渐揭示。

- **大招就绪指示**
  - 在角色头像的**右上角**加一个**绿色小圆点**。
  - 圆点亮起 = 大招/终极技能已就绪，可以释放。
  - 圆点熄灭/灰色 = 大招尚未就绪或正在冷却。

## 待细化

- 遮罩颜色、透明度、方向（从上到下 / 从下到上 / 环形）。
- 绿色圆点的具体大小、动画（是否呼吸闪烁提示）。
- 是否同时显示具体冷却数字。
- 是否区分“引导中”和“冷却中”两种状态表现。
