## 今日铁律/经验

- 审查发现"24处 .Value 有 Nullable 空引用风险"→ 实际绝大多数是 Dictionary.Values 属性，不是 Nullable<T>.Value → **审查 .Value 时必须区分集合属性和 Nullable 类型**
- EnterGameHandler 覆盖内存但不持久化 → 数据库中保留战斗后属性，内存每次重置 → **登录流程不应覆盖已持久化的属性**
- async void 是 C# 反模式 → **网络连接方法应改 async Task**
