## 🔥 HP 同步链路断裂（14:56 新发现）

**问题描述**：MapPlayerState.Hp 和 Role.Hp 是两个独立值，战斗系统只修改前者，AutoSave 只保存后者，两者之间没有同步机制。

**数据流**：
```
战斗系统 → legacy MapState.Hp → SyncCombatHp → MapPlayerState.Hp ✅
AutoSave → role.Hp → MongoDB ✅
MapPlayerState.Hp → role.Hp ❌ （缺失！）
```

**影响**：
- 玩家战斗受伤后，MapPlayerState.Hp 正确减少，但 Role.Hp 仍是登录时的值
- 5 分钟 AutoSave 保存过时的 Role.Hp 到数据库
- 玩家下线后再上线，EnterGameHandler 读 role.Hp（过时值），PlayerSnapshot 用 hp（满血值）

**修复方案（两层）**：
1. 即时修复：EnterGameHandler PlayerSnapshot 改为 `Hp = role.Hp, MaxHp = hp, Mp = role.Mp, MaxMp = mp`
2. 根因修复：AutoSave 中增加 MapPlayerState → Role 回写（从 MapService 读取当前 HP 写回 Role）

**具体代码修改（即时修复）**：
```csharp
// EnterGameHandler.cs 第97行
// 修改前
Hp = hp, MaxHp = hp, Mp = mp, MaxMp = mp,
// 修改后
Hp = role.Hp, MaxHp = hp, Mp = role.Mp, MaxMp = mp,
```

**具体代码修改（根因修复）**：
```csharp
// Program.cs AutoSave 循环中，在 await playerSession.Roles.Update 之前添加
var mapPlayer = mapService.GetPlayerOnMap(role.CurrentMap, accountId);
if (mapPlayer != null)
{
    role.Hp = mapPlayer.Hp;
    role.Mp = mapPlayer.Mp;
    role.MaxHp = mapPlayer.MaxHp;
    role.MaxMp = mapPlayer.MaxMp;
}
```
