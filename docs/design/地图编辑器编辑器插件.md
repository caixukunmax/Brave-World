# 地图编辑器 · 编辑器插件化（不运行游戏改地图）

> 状态：V1.0 设计稿
> 关联文档：《地图编辑器多地图支持.md》（运行时多地图能力，本文在其数据层之上做编辑器化）
> 决策依据（用户确认）：功能范围 = 地形 + 装饰 + 多地图；承载形态 = 底部大画布面板；代码策略 = 抽共享逻辑，运行时 MapEditor 与插件共用。

## 1. 概述与目标

当前 `clinetcsharp/Scripts/MapEditor*.cs` 是一套**运行时**地图编辑器：必须按 F5/F6 跑起游戏、进入编辑模式后，由 `UIInputPolicy`/`CameraController` 接管输入、`MapEditor` 节点暂停游戏并隐藏各运行时 Manager，才能改地图配置（`res://maps/<name>/map.json`）。

目标：把它改造成 **Godot 编辑器插件**（`addons/map_editor_editor/`），**不开游戏**即可在编辑器底部面板里编辑地图（刷地形、摆/移/删装饰、多地图新建/切换/删除/重命名/保存）。

### 为什么不新建一套而是抽共享逻辑
编辑操作（刷地形、装饰占位/重叠判定、框选、撤销重做、扩图、存读）本质都是对 `GridData`（`Dictionary<Vector2I, GridCell>`）的纯数据修改，与"游戏是否运行"无关。运行时的强依赖（输入策略、相机、各 Manager 隐藏、游戏暂停）只是"运行游戏的副作用"。把纯数据逻辑抽成 `MapEditController`，运行时 MapEditor 与插件都调用它，行为一致、不重复、易维护。

## 2. 总体架构

```
┌─ Godot 编辑器 ─────────────────────────────────────────────┐
│ 底部面板(Monster? BottomPanel): MapEditorBottomPanel         │
│  ├─ 左/右工具区(Control)                                     │
│  │   ├─ 地图列表(OptionButton + 新建/删除/重命名)            │
│  │   ├─ 工具切换(刷地形 / 放建筑 / 选择 / 橡皮擦)            │
│  │   ├─ 地形调色板                                           │
│  │   ├─ 建筑图鉴(搜索)                                       │
│  │   └─ 保存 / 撤销 / 重做 / 缩放滑条                        │
│  └─ 画布区(SubViewportContainer, MouseFilter=Stop)           │
│       └─ SubViewport(Always)                                 │
│           ├─ GridManager(SkipAutoLoad, 手动灌 GridData)      │  ← 渲染地形/网格
│           ├─ Camera2D(编辑器自管 pan/zoom)                   │
│           ├─ MapEditViewport(Node2D, 输入捕获)               │  ← 转网格坐标→调 Controller
│           └─ MapEditDecorationOverlay(Node2D, _Draw)         │  ← 画装饰占地块/选中高亮
└──────────────────────────────────────────────────────────────┘
        │ 调用
        ▼
  MapEditController(GridManager, 选择, Undo/Redo, 纯数据编辑)
        │ 画布/选择变化 → OnVisualChanged 回调
        ├─ 插件实现: grid.UpdateGridShaderOverlay()+NotifyTerrainChanged(); _overlay.QueueRedraw()
        └─ 运行时实现: grid.UpdateGridShaderOverlay()+NotifyTerrainChanged(); grid.SyncDecorations()
        │ 存读
        ▼
  MapDataManager.(Load|Save)MapToJson(静态, 编辑器安全) → res://maps/<name>/map.json + tables/MapConfig 同步
  DecorationConfigUtil.LoadFromProfiles(profiles) ← ProfileConfigIO.LoadFromFile()
```

## 3. 模块设计

### 3.1 共享核心：`MapEditController`（新建，`clinetcsharp/Scripts/MapEditController.cs`）
- `[Tool]` 不需要；它是普通 `RefCounted`/class，**不继承 Node、不依赖任何运行时单例**。
- 字段：`GridManager Grid`（由调用方注入）、`GridData Data => Grid.GridData`、选择集合、撤销/重做栈。
- 构造：`MapEditController(GridManager grid)`。
- 纯数据 API（与运行时现有逻辑一一对应，直接迁移现有实现，仅把 `grid` 引用换成 `Grid`）：
  - `PaintTerrain(IEnumerable<Vector2I> cells, int terrainType, int? attribute = null)`
  - `PlaceDecoration(Vector2I anchor, int decorationType)`（含 footprint 重叠校验，复用现有 `GetFootprintCells`/`IsFootprintFree`）
  - `MoveDecoration(Vector2I from, Vector2I to)` / `DeleteDecoration(Vector2I anchor)`
  - `SelectBox(Rect2I / 两角)` → 维护选择集合；`ClearSelection()`
  - `ApplyTerrainToSelection(int terrainType)` / `ApplyDecorationToSelection(int type)`
  - `ExtendMap(...)`（迁移 `ExtendMapCommand`）
  - `Undo()` / `Redo()`
  - `LoadMap(string name)` → `MapDataManager.LoadMapFromJson` 注入 `Grid.GridData` + 设置 `MapWidth/Height/Name`
  - `SaveMap()` → `MapDataManager.SaveMapToJson(Grid, Grid.MapName)`
  - `CreateNewMap(string name, int w, int h)` / `DeleteMap(name)` / `RenameMap(old,new)`（走 `MapDataManager` 静态方法）
- 回调：`event Action OnVisualChanged`；所有数据变更后触发（控制器不直接调用 `grid.SyncDecorations()`，改为触发回调，使插件可换成"画占地块"而非生成 `MapDecoration` 节点）。
- 撤销命令类（`TerrainEditCommand` / `DecorationEditCommand` / `SelectionEditCommand` / `ExtendMapCommand`）：从 `MapEditor.Undo.cs` 迁移到控制器内（或 `MapEditCommands.cs`），`grid` 字段改为 `Controller.Grid`，命令体内的视觉刷新改为 `Controller.OnVisualChanged?.Invoke()`。

### 3.2 编辑器插件（`addons/map_editor_editor/`）
- `plugin.cfg`：`name="Map Editor (Editor)"`、`script="MapEditorPlugin.cs"`。
- `MapEditorPlugin.cs`（`[Tool] EditorPlugin`）：
  - `_EnterTree`：`_panel = new MapEditorBottomPanel(); AddControlToBottomPanel(_panel, "地图编辑器");`
  - `_ExitTree`：`RemoveControlFromBottomPanel(_panel); _panel.QueueFree();`
- `MapEditorBottomPanel.cs`（`[Tool] Control`）：建 UI + 持有 `GridManager`/`Camera2D`/`MapEditViewport`/`MapEditDecorationOverlay`，并创建 `MapEditController` 绑定 `GridManager`。
  - 首次 `_Ready`：加载建筑图鉴 → `var profiles = ProfileConfigIO.LoadFromFile(); DecorationConfigUtil.LoadFromProfiles(profiles);`；默认载入第一张地图（`MapDataManager.GetMapNames()` 取首个）。
  - `OnVisualChanged` 实现：`Grid.UpdateGridShaderOverlay(); Grid.NotifyTerrainChanged(); _decorationOverlay.QueueRedraw();`
  - 工具区按钮 → 切换 `_currentTool` / `_currentTerrainType` / `_currentDecorationType`；地图列表 → 调 `Controller.LoadMap/SaveMap/CreateNewMap/...` 并刷新。
  - 缩放滑条 → `Camera2D.Zoom`；保存按钮 → `Controller.SaveMap()`。
- `MapEditViewport.cs`（`[Tool] Node2D`，挂在 SubViewport 内）：`override _UnhandledInput(InputEvent e)` 处理鼠标：
  - 中键拖 / 空格+左键 → 平移 `Camera2D.Position`（屏幕 delta → `Camera2D` 世界位移）。
  - 滚轮 → `Camera2D.Zoom`（限幅，如 0.2~4）。
  - 左键按下/拖动（工具=刷地形/放建筑/橡皮擦/选择）→ 用 `GridManager.ToLocal(GetGlobalMousePosition())` 经 `WorldToGrid` 得到网格坐标，调用 `Controller.PaintTerrain/PlaceDecoration/SelectBox/...`。
  - `SubViewportContainer.MouseFilter = Stop`（对齐调试面板插件，保证事件进 SubViewport）。
- `MapEditDecorationOverlay.cs`（`[Tool] Node2D`，`_Draw`）：
  - 遍历 `Grid.GridData`，对 `DecorationType != 0` 的格子，按 `DecorationConfigUtil.Get(type)` 的 `Color`/`SizeX`/`SizeY` 画占地矩形 + 边框 + 名称标签（不生成 `MapDecoration` 节点，避免运行时副作用）。
  - 画选择高亮（半透明黄框）。

### 3.3 运行时 MapEditor 重构（共用，保持行为不变）
- `MapEditor.Core.cs` 等：保留 `EnterEditMode`/`ExitEditMode`（暂停游戏、隐藏各 Manager、显示 `_editGridManager`），但把内联的刷地形/装饰/选择/撤销逻辑改为调用 `MapEditController`（`_controller = new MapEditController(_editGridManager)`）。
- 输入转换保持原有 `GridManager.ToLocal(GetGlobalMousePosition())` → `WorldToGrid`，转发给 `_controller`。
- `_controller.OnVisualChanged` 实现：`_editGridManager.UpdateGridShaderOverlay(); _editGridManager.NotifyTerrainChanged(); _editGridManager.SyncDecorations();`（保持与现有运行时渲染一致，仍生成 `MapDecoration` 节点）。
- 这样运行时与插件**数据层 100% 共用**，仅渲染/输入来源不同。

### 3.4 建筑图鉴编辑器安全加载（修复 `DecorationConfigUtil` 编辑器为空）
- 新增静态方法 `DecorationConfigUtil.LoadFromProfiles(Dictionary<int, EntityProfile> profiles)`：把现有 `RefreshFromProfileManager()` 中"遍历 `EntityProfileManager.Instance.GetProfilesByType("decoration")`"的逻辑，改为遍历传入的 `profiles`（按 `entityType=="decoration"` 过滤），其余（取 appearance/labels/obstacle/category、算 Color/SizeX/SizeY）不变。
- 运行时仍走 `RefreshFromProfileManager()`（从 `Instance`）；插件走 `LoadFromProfiles(ProfileConfigIO.LoadFromFile())`。两者填充同一 `Configs`。

## 4. 数据流与保存（编辑器内）
- 加载：`MapDataManager.GetMapNames()`（静态，`DirAccess` 扫 `res://maps/`）→ 列表；`MapDataManager.LoadMapFromJson(name)` → `GridData` 注入 `GridManager`。
- 保存：`MapDataManager.SaveMapToJson(Grid, name)` → 写 `res://maps/<name>/map.json`，并同步 `tables/MapConfig/<name>.bytes`（沿用现有逻辑）。
- 以上均为 `static` + Godot 文件 API，编辑器内可用（与调试面板 `ProfileConfigIO` 同理）。

## 5. 风险与验证点（实现前需小样确认）
1. **SubViewport 内鼠标坐标映射**：候选 `GridManager.ToLocal(GetGlobalMousePosition())`（运行时同款）。若 `GetGlobalMousePosition()` 在 SubViewport 下返回主视口坐标导致错位，则改用 `event.position` 经 `subViewport.GetCanvasTransform().AffineInverse()` 换算。需先写最小验证样。
2. **`MapDataManager.SaveMapToJson` 的 `tables/MapConfig` 同步步骤**（`MapConfigTable.WriteMapConfig`）编辑器安全性：若依赖运行时/Unity 资源，则插件保存先只写 `map.json`，tables 同步留待构建期；需确认。
3. `GridManager` 在 `SkipAutoLoad` + 手动 `GridData` 的 SubViewport 下渲染地形/网格（PreviewMap 已证明可行，低概率风险）。
4. Camera2D 在 SubViewport 下的 pan/zoom（标准用法，低概率风险）。

## 6. 实施步骤（分阶段，每阶段可独立验证）
- **P0 脚手架**：`plugin.cfg` + `MapEditorPlugin` 注册底部面板 + 空 `MapEditorBottomPanel`；编辑器启用插件后出现空面板。
- **P1 渲染与相机**：面板内 SubViewport + GridManager(SkipAutoLoad) + Camera2D + 加载首张地图并渲染；中键平移/滚轮缩放可用。
- **P2 共享核心**：抽取 `MapEditController` + 迁移撤销命令；先接"刷地形"到面板（验证坐标映射风险点 1）。
- **P3 装饰**：`DecorationConfigUtil.LoadFromProfiles` + 建筑图鉴 + `MapEditDecorationOverlay` 画占地块 + 摆/移/删装饰。
- **P4 多地图**：地图列表 新建/切换/删除/重命名 + 保存（验证风险点 2）。
- **P5 运行时共用**：`MapEditor` 改为调 `MapEditController`，保留冻结逻辑；行为回归验证（与改造前一致）。

## 7. 测试
- 编辑器内：不运行游戏，刷地形→保存→重开编辑器→加载确认地形在；摆建筑→保存→确认 `map.json` 中 `DecorationType` 与占地正确；新建/删除/重命名地图生效；撤销/重做正确。
- 运行时：进入游戏编辑模式，确认刷地形/装饰/选择/撤销与改造前一致（共用控制器）。
- 边界：footprint 重叠拒绝、地图边界外坐标忽略、装饰 id=0(None) 视为清除。
