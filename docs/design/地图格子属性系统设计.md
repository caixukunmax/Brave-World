# 地图格子属性系统（Terrain/Tile Properties）设计文档

- **版本**: v1.0
- **日期**: 2026-05-16
- **作者**: 狗剩
- **状态**: 设计阶段，待陛下确认后建单

---

## 1. 系统现状

### 客户端已有
- `GridCell` 有 6 个属性：`Exists`/`Walkable`/`Visible`/`TerrainType`/`Height`/`CustomData`
- `TerrainType` 当前定义：0=普通, 1=水, 2=草地, 3=沙地, 4=岩石, 5=雪地, 6=沼泽
- `GridManager.DrawWalkableOverlay()` 已能渲染地形颜色（半透明叠加）
- 地图数据以 CSV 格式存储在客户端本地（`MapDataManager` 读写）

### 服务端现状
- `MapState` = 玩家 + 怪物 + NPC 的集合，**完全没有格子概念**
- `WorldState._reservedCells` 仅用于移动预占（临时状态）
- 服务端不存储/不查询任何地形信息
- 移动检查只判断 `IsOccupied`（有无实体），不判断地形

### 缺失的能力
| 能力 | 现状 | 影响 |
|---|---|---|
| 地形类型配置表 | 无 Luban 表 | 无法策划配置 |
| 服务端格子属性存储 | 无数据结构 | 服务端无法判断地形 |
| 地形对移动的影响 | 未实现 | 水域=可游泳？不可走？ |
| 地形对战斗的影响 | 未实现 | 草地减速？水域加冰伤？ |
| 地形视觉效果 | 仅颜色叠加 | 无纹理/动画/粒子 |
| 地形同步协议 | 无 | 新进玩家看不到地形 |

---

## 2. 设计目标

1. **配置驱动**：所有地形属性走 Luban 配置表，策划可配
2. **双端一致**：服务端是权威端，地形影响由服务端判定
3. **向后兼容**：现有地图 CSV 格式不变，新增字段可空
4. **分阶段实现**：先核心（配置+存储+移动影响），后扩展（战斗影响+视觉效果）

## 3. 配置表设计（Luban）

### 3.1 新增 bean: TerrainConfig

```protobuf
// __beans__.xlsx 新增
TerrainConfig {
    Id:int            // 地形类型ID (0=普通, 1=水域, 2=草地...)
    Name:string       // 显示名称
    Description:string
    
    // 移动属性
    Walkable:bool     // 是否可行走
    MoveSpeedRatio:float  // 移动速度倍率 (1.0=正常, 0.5=减半, 0=不可走)
    CanSwim:bool      // 是否可游泳（如果角色有游泳能力）
    
    // 战斗属性
    PatkModifier:float    // 物理攻击修正 (1.0=正常, 1.2=+20%)
    MatkModifier:float    // 魔法攻击修正
    PdefModifier:float    // 物理防御修正
    MdefModifier:float    // 魔法防御修正
    HpRegenPerSec:int     // 每秒HP恢复（泉水类地形）
    MpRegenPerSec:int     // 每秒MP恢复
    
    // 元素亲和
    FireDamageBonus:int   // 火系伤害加成（+5 = +5点）
    IceDamageBonus:int    // 冰系伤害加成
    PoisonDamageBonus:int // 毒系伤害加成
    
    // 视觉属性（客户端用）
    ColorR:int        // 叠加色 R (0-255)
    ColorG:int        // 叠加色 G
    ColorB:int        // 叠加色 B
    ColorA:float      // 叠加透明度 (0-1)
    ParticleEffect:string // 粒子效果路径（可选）
}
```

## 4. 服务端设计

### 4.1 新增数据结构

```csharp
// WorldDataTypes.cs 新增

/// <summary>
/// 地图格子属性 — 服务端权威地形数据
/// </summary>
public class MapTileData
{
    public int X { get; set; }
    public int Y { get; set; }
    public int TerrainType { get; set; } = 0;
    public int Height { get; set; } = 0;
    
    // 运行时计算属性（从 TerrainConfig 表读取）
    public bool IsWalkable => _config?.Walkable ?? true;
    public float MoveSpeedRatio => _config?.MoveSpeedRatio ?? 1.0f;
    
    private TerrainConfigRow? _config;
    
    public void SetConfig(TerrainConfigRow? config) => _config = config;
}

/// <summary>
/// 地图运行时状态扩展 — 加入格子属性
/// </summary>
public class MapState
{
    public int MapId { get; set; }
    public ConcurrentDictionary<long, MapPlayerState> Players { get; } = new();
    public ConcurrentDictionary<long, MapMonsterState> Monsters { get; } = new();
    public ConcurrentDictionary<long, MapNpcState> Npcs { get; } = new();
    
    // 新增：格子属性矩阵 (x,y) → MapTileData
    // 使用 Dictionary 而非二维数组，支持不规则地图
    public Dictionary<(int x, int y), MapTileData> Tiles { get; } = new();
    
    // 地图尺寸
    public int Width { get; set; } = 50;
    public int Height { get; set; } = 50;
}
```

### 4.2 地图加载时初始化格子

```csharp
// MapService.cs 或 WorldState.cs

/// <summary>
/// 加载地图时，从客户端 CSV 或 Luban 地图配置初始化格子属性
/// </summary>
public void InitMapTiles(string mapName, LubanTableLoader tables)
{
    var mapState = GetOrCreateMap(mapName);
    var mapConfig = tables.MapConfigs.Values.FirstOrDefault(m => m.MapName == mapName);
    
    if (mapConfig == null) return;
    
    mapState.Width = mapConfig.Width;
    mapState.Height = mapConfig.Height;
    
    // 从 CSV 加载地形数据（客户端生成的地图文件）
    var tileData = LoadTileDataFromCsv(mapName);
    
    foreach (var (pos, terrainType, height) in tileData)
    {
        var tile = new MapTileData 
        { 
            X = pos.x, 
            Y = pos.y, 
            TerrainType = terrainType,
            Height = height
        };
        
        // 绑定地形配置
        var terrainConfig = tables.GetTerrainConfig(terrainType);
        tile.SetConfig(terrainConfig);
        
        mapState.Tiles[(pos.x, pos.y)] = tile;
    }
}
```

### 4.3 移动系统地形检查

```csharp
// MoveHandler.cs 或 WorldState.cs

public bool IsTileWalkable(string mapName, int x, int y, long entityId)
{
    var map = GetMap(mapName);
    if (map == null) return false;
    
    // 边界检查
    if (x < 0 || x >= map.Width || y < 0 || y >= map.Height) return false;
    
    // 地形检查
    if (map.Tiles.TryGetValue((x, y), out var tile))
    {
        // 不可走地形
        if (!tile.IsWalkable) return false;
        
        // 水域需要游泳能力（未来扩展）
        // if (tile.TerrainType == 1 && !entity.CanSwim) return false;
    }
    
    // 实体占用检查（已有逻辑）
    return !IsOccupied(mapName, x, y);
}

/// <summary>
/// 获取格子的移动速度倍率（用于地形减速/加速）
/// </summary>
public float GetTileMoveSpeedRatio(string mapName, int x, int y)
{
    var map = GetMap(mapName);
    if (map?.Tiles.TryGetValue((x, y), out var tile) == true)
    {
        return tile.MoveSpeedRatio;
    }
    return 1.0f; // 默认正常速度
}
```

### 4.4 战斗系统地形影响

```csharp
// CombatManager.cs

/// <summary>
/// 计算地形对伤害的修正
/// </summary>
public int ApplyTerrainDamageModifier(long attackerId, long targetId, int baseDamage, 
    string damageType, Dictionary<string, MapState> maps)
{
    // 获取目标位置的地形
    var target = FindEntity(targetId, maps);
    if (target == null) return baseDamage;
    
    var map = maps.GetValueOrDefault(target.CurrentMap);
    if (map == null) return baseDamage;
    
    if (!map.Tiles.TryGetValue((target.GridX, target.GridY), out var tile))
        return baseDamage;
    
    var terrain = _tables?.GetTerrainConfig(tile.TerrainType);
    if (terrain == null) return baseDamage;
    
    // 元素伤害加成
    var bonus = damageType switch
    {
        "fire" => terrain.FireDamageBonus,
        "ice" => terrain.IceDamageBonus,
        "poison" => terrain.PoisonDamageBonus,
        _ => 0
    };
    
    // 攻防修正
    float modifier = damageType.Contains("magic") 
        ? terrain.MatkModifier 
        : terrain.PatkModifier;
    
    return (int)((baseDamage + bonus) * modifier);
}
```

```csharp
// GridManager.cs — 渲染逻辑改造

private Color GetTerrainColor(int terrainType)
{
    // 优先从 Luban 配置读取颜色，fallback 到硬编码
    var config = _terrainConfigs?.GetValueOrDefault(terrainType);
    if (config != null)
    {
        return new Color(
            config.ColorR / 255f,
            config.ColorG / 255f,
            config.ColorB / 255f,
            config.ColorA
        );
    }
    
    // Fallback 硬编码
    return terrainType switch
    {
        1 => new Color(0.2f, 0.4f, 0.8f, 0.3f),  // 水
        2 => new Color(0.2f, 0.8f, 0.2f, 0.2f),  // 草地
        3 => new Color(0.9f, 0.8f, 0.4f, 0.2f),  // 沙地
        4 => new Color(0.5f, 0.5f, 0.5f, 0.3f),  // 岩石

    };
```

## 6. 实现阶段

### Phase 1: 配置表 + 客户端渲染（1-2天）
- [ ] Luban 新增 `TerrainConfig` bean + `TbTerrainConfig` 表
- [ ] 填充 9 种地形配置数据
- [ ] 客户端 `GridCell` 绑定 Luban 配置
- [ ] `GridManager` 渲染逻辑改配置驱动
- [ ] 编辑模式支持地形刷选工具

### Phase 2: 服务端集成（2-3天）
- [ ] 服务端 `MapState.Tiles` 数据结构
- [ ] 地图加载时初始化格子属性
- [ ] 移动系统接入地形检查（`IsTileWalkable`）
- [ ] 移动速度倍率（地形减速）

- [ ] 元素伤害加成（火/冰/毒）
- [ ] 防御修正（岩石地形加物防等）

### Phase 4: 视觉升级（可选，2-3天）

- [ ] 岩浆发光效果

## 7. 数据流

```
策划配置 (TbTerrainConfig.xlsx)
    ↓ build_tables.ts
Luban JSON (terrain_config.json)
    ↓ 客户端/服务端各自加载

客户端:
    LubanTableLoader.TerrainConfigs → GridCell.TerrainConfig
    → GridManager.GetTerrainColor() / DrawTerrainEffects()

服务端:
    LubanTableLoader.TerrainConfigs → MapTileData._config
    → IsTileWalkable() / GetTileMoveSpeedRatio()
    → CombatManager.ApplyTerrainDamageModifier()
    → MapInfoSyncNotify.tiles → 客户端同步
```

## 8. 风险评估

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| CSV 地形数据与服务端不同步 | 中 | 玩家看到的地形和服务端判定不一致 | 服务端作为权威，登录时从服务端拉取完整地形 |
| 大量格子同步消息过大 | 低 | 50x50=2500个格子，消息体积大 | 只同步非默认地形（0=普通）的格子；或做区域同步 |
| 地形粒子性能开销 | 中 | 低端设备卡顿 | 粒子效果可配置开关；远距离不渲染 |
| 移动减速影响手感 | 低 | 沙地/沼泽减速可能让玩家觉得"卡" | 减速幅度策划可控（配置表）；提供视觉反馈 |
