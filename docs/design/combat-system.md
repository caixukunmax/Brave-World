# 战斗系统设计稿（Combat System Design）

> 版本：V0.3  
> 状态：核心玩法已确认，可进入技术设计

---

## 1. 设计目标

构建一套**"碰撞触发 + 大地图内半自动 ATB 战斗"**系统：

- **低门槛**：玩家只需控制移动，攻击/技能自动释放。
- **高策略**：通过走位（卡距离、拉扯、风筝）直接影响战斗结果。
- **强反馈**：碰撞即开战，节奏明快，没有传统"切屏读条"的顿挫感。
- **真实感**：战斗随时可进可退，大地图上没有"安全气泡"，第三方可以随时被卷入。

---

## 2. 战斗触发机制

### 2.1 主动碰撞（Initiative Collision）

- **大地图上所有角色（玩家与玩家、玩家与怪物、怪物与怪物）均不能占据同一格子**。
- **在大地图上，角色与角色/怪物发生主动碰撞时触发战斗判定**。
- 战斗不切换场景、不加载副本，直接在当前大地图坐标上进入战斗状态。
- **优先级规则**：
  - 若碰撞双方**均未处于战斗状态**：
    - **玩家主动撞向野怪** → 玩家获得**先手攻击权**（First Strike）。
    - 野怪受攻击后，正式进入战斗。
  - 若有一方**已在战斗中**：
    - **不免疫碰撞**：第三方路过时仍可能因碰撞、技能溅射等原因被卷入新的或已有的战斗关系（见 2.3）。

### 2.2 先手攻击（First Strike）

- 先手方在碰撞瞬间立即执行一次**普攻**（或预设的"碰撞技能"）。
- 这次攻击不消耗 ATB 条，作为进入战斗的过渡动作。
- 随后双方正式进入 ATB 循环。

### 2.3 第三方卷入（真实世界规则）

- 大地图上**不存在战斗隔离区**。
- 第三方角色或怪物如果：
  - **主动碰撞**了正在战斗中的角色/怪物；
  - **被范围技能波及**并满足了战斗触发条件；
- 则该第三方会被纳入战斗关系，开始独立计算自己的 ATB。
- 战斗关系是**动态网状**的：A 与 B 战，C 撞了 B → C 与 B 进入战斗；此时 A、B、C 三者处于相互可攻击状态（具体仇恨目标由 AI 决定）。

## 3. 战斗属性（Combat Attributes）

| 属性 | 作用说明 |
|------|----------|
| **血量（HP）** | 生命值为 0 时角色战败/撤退。 |
| **护甲（Armor）** | 物理减伤层（具体公式待技术设计时确定）。 |
| **蓝条（MP）** | 释放技能消耗的资源，普攻不消耗。 |
| **物攻（PATK）** | 影响物理伤害。 |
| **法攻（MATK）** | 影响法术伤害。 |
| **物防（PDEF）** | 降低受到的物理伤害。 |
| **法防（MDEF）** | 降低受到的法术伤害。 |
| **移动速度（Move Speed）** | 影响大地图移动速度；**战斗中移速与大地图移速一致**。 |
| **迅捷（Agility）** | **核心属性**：决定 ATB 行动条的积累速度。迅捷越高，出手频率越快。 |

## 4. 核心战斗机制：ATB 行动条

### 4.1 行动条规则

- **每个角色在同一时刻只拥有一条 ATB 行动条**（0 ~ 100）。
- **"战斗"对角色而言是一种状态**，进入战斗状态后 ATB 从 0 开始自动积累。
- 当 ATB 达到 **100** 时，该角色获得一次**行动机会**，自动选择并释放技能。
- **无论角色同时与多少目标交战，都只有这一条 ATB**。不会因为 1 打多就变成多条 ATB。

### 4.2 积累速度公式

```
ATB 增速 = 基础速率 × 迅捷系数
```

- **基础速率**：所有角色共享的全局常数。
- **迅捷系数**：由角色"迅捷"属性决定，迅捷越高系数越大。

### 4.3 普攻即技能

- **普通攻击被抽象为一个"零消耗、短冷却（或无冷却）的技能"**。
- 所有 AI 判定逻辑统一走"技能选择"流程。

---

## 5. 战斗中的角色控制与 AI

### 5.1 玩家可控 vs 自动战斗

- **玩家可以持续控制角色在大地图上移动**（移速 = 大地图移速）。
- **当角色 ATB=100 时，自动战斗 AI 选择并释放技能**。
- 玩家不需要手动点技能，通过走位间接指挥战斗节奏。

### 5.2 距离尊重原则（Range Respect）

> **AI 不得为了释放近战技能而自动走回敌人身边。**  
> **AI 只能在"当前位置可释放"的技能中进行选择。**

- 每条技能需具备**施法距离**属性。
- 当角色 ATB 满时，AI 的决策顺序：
  1. 筛选**当前位置满足施法距离**且**不在冷却中**的技能。
  2. 从中按优先级（伤害最高 / 性价比最优）选择一项释放。
  3. 若列表为空（玩家跑太远，所有技能都打不到）：
     - 角色**本次不执行任何动作**，ATB 清零。
     - 作为补偿，**下一次 ATB 积累获得额外加速**（具体倍率待技术设计时确定）。

## 6. 多方参战规则

### 6.1 独立战斗关系，但单角色单 ATB

- 每个玩家与每个怪物的碰撞，都会建立一条**独立的战斗关系**。
- **同一个角色可以同时与多个目标建立战斗关系**，但自身**只有一条 ATB**。
- 当该角色 ATB=100 时，AI 会根据当前所有战斗关系中的目标，选择最优目标释放技能。

> **示例场景**：
> - 玩家 A 碰撞野怪 M1 → A 与 M1 建立战斗关系。
> - 玩家 A 又碰撞野怪 M2 → A 与 M2 也建立战斗关系。
> - A 只有一条 ATB。ATB 满时，AI 评估 M1、M2 的距离和威胁，选择其中一个释放技能。
> - M1 和 M2 各自也分别与 A 建立战斗关系，它们各自拥有独立的 ATB。

### 6.2 己方援助

- 两名玩家同时与同一个怪物战斗时，**怪物会同时与两名玩家建立战斗关系**。
- 当前设计不强制组队，但允许"自然协作"——谁先打到算谁的，怪物按 AI 逻辑选择目标攻击。

## 7. 脱战机制（Disengage）

满足以下**任一条件**即可脱战：

### 条件 1：安全脱离
- 双方距离 **> A**（较近阈值）。
- 并且，在最近 **T1 秒**内，双方**没有互相造成过伤害**。
- 并且，维持上述状态持续 **S1 秒**。

### 条件 2：彻底逃离
- 双方距离 **> B**（较远阈值，**B > A**）。
- 维持该状态持续 **S2 秒**（通常 **S2 ≤ S1**）。

### 7.1 脱战后行为

- **怪物**：进入**缓慢回血**状态，直到回满或再次被拉入战斗。
- **玩家**：可以正常移动、嗑药、休整；若再次碰撞则重新进入战斗。

---

## 8. 胜利与失败

- **怪物胜利条件**：玩家血量归 0 或玩家成功脱战。
- **玩家胜利条件**：怪物血量归 0。
- **玩家死亡惩罚**：
  - 在当前地图的**玩家出生点复活**。
- **怪物死亡奖励**：
  - 经验、掉落物分配机制待技术设计时确定（可考虑按伤害贡献分配）。

---

## 9. 视觉与体验建议

1. **战斗光环**：进入战斗后，角色脚下出现轻微光效，方便玩家快速识别自己是否还在战斗中。
2. **微型 ATB 条**：仅在玩家自己的角色头顶显示一个极细的进度条，提醒自己下一次自动出手的时间。
3. **先手突进**：碰撞瞬间给玩家一个 0.1~0.2 秒的微小突进/停顿，增强"撞上去"的打击感。
