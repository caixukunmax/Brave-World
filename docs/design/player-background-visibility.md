# 玩家背景颜色可见性

## 1. 背景

当前玩家背景颜色调整链路本身是通的，但用户会感知为：

- 怪物 / NPC 改背景颜色很明显
- 玩家改背景颜色几乎没效果

这不是颜色没有写进去，而是玩家背景的历史默认可见度过低。

## 2. 根因

玩家默认外观配置长期使用：

- `BgOpacity = 0.1`

而怪物 / NPC 默认是：

- `BgOpacity = 0.9`

在近期“边框向内吃”的实体本体绘制规则下，玩家内部可见填充面积更小，
再叠加 `0.1` 的低不透明度，背景颜色变化就更容易被误判成“无效”。

## 3. 目标

1. 玩家背景颜色调整应当肉眼可见
2. 不改变“玩家整体比怪物更轻”的视觉方向
3. 对历史未自定义过的玩家默认配置做平滑兼容

## 4. 方案

### 4.1 提高玩家默认背景不透明度

将玩家默认 profile 的背景不透明度从 `0.1` 提高到 `0.35`。

这是一个折中值：

- 明显高于旧值，颜色变化可见
- 仍显著低于怪物 / NPC 的 `0.9`

### 4.2 兼容旧配置

对历史玩家 profile 做轻量归一化，仅处理“看起来仍是旧默认”的情况：

- `entity_type = player`
- `BgOpacity` 仍约等于 `0.1`
- `BgColor` 仍接近默认白色

满足以上条件时，自动提升到新的默认可见度。

如果用户已经显式改过背景色或不透明度，则不强行覆盖。

### 4.3 旧格式迁移默认值

在 legacy `player` section 缺少 `bg_opacity` 时，兼容默认值也同步改为新默认可见度。

## 5. 验收标准

1. 新玩家默认外观下，改背景颜色能明显看出差别
2. 老玩家若仍停留在旧默认外观，升级后背景颜色变得可见
3. 已显式自定义过背景色/不透明度的玩家配置不被粗暴覆盖
