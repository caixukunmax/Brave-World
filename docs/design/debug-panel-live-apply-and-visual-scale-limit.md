# 调试面板即时生效与角色比例极限修正

> 版本：v0.1
> 状态：实施中
> 范围：`clinetcsharp/Scripts/Components/AppearanceComponent.cs`、`EntityBase.cs`

## 1. 问题

当前有两个体验问题：

1. 调试面板里通过手动输入精确值修改外观参数时，不一定立刻生效
2. `角色比例 = 1.0` 的语义不对，当前更像“填充矩形占满格子”，边框还会继续压出格子外

## 2. 根因

### 2.1 手动输入不即时

`AppearanceComponent` 的大小/边框比例联动目前主要挂在 `DragEnded`：

1. 拖动滑条结束时才触发联动计算
2. 直接通过 `LineEdit` 精确输入时，只会改 `slider.Value`
3. 不会触发 `DragEnded`

于是就出现“数值显示变了，但实体没有马上应用”的假象。

### 2.2 比例 1.0 的边界语义错误

当前 `VisualSize` 直接按 `GridSize * VisualSizeScale` 计算，而边框又是额外描边。

这意味着：

1. `scale = 1.0` 时，填充区域已经顶满格子
2. 边框再向外扩半个描边宽度
3. 最终视觉外轮廓会压出格子

这和用户想要的语义相反。正确语义应为：

`scale = 1.0` 时，**包含边框在内的总视觉外轮廓**刚好撑满格子，但不能越界。

## 3. 目标

1. 手动输入、点击外部确认、按回车确认，都要立即生效
2. `角色比例` 的控制语义改为“控制总外轮廓尺寸”
3. 边框越粗，内部填充矩形应自动缩一点，保证总视觉外轮廓不越格

## 4. 方案

### 4.1 外观组件即时联动

`AppearanceComponent` 的四条联动控制：

1. 角色大小
2. 角色比例
3. 边框粗细
4. 边框比例

统一改成在 `ValueChanged` 上即时完成：

1. 联动另一侧滑条显示
2. 更新显示值
3. 触发 `OnChanged -> ApplyProfileToAll`

不再依赖 `DragEnded` 作为唯一提交点。

### 4.2 外轮廓尺寸语义

引入区分：

1. `VisualOuterSize`
   - 外轮廓总尺寸
   - 由 `GridSize * VisualSizeScale` 决定
2. `VisualSize`
   - 实际填充矩形尺寸
   - 由 `VisualOuterSize - BorderWidth` 决定

这样：

1. `scale = 1.0` 时，外轮廓总尺寸 = 格子尺寸
2. 边框自动吃掉一部分内部空间
3. 最终视觉不会压过格子边界

## 5. 验收标准

1. 在调试面板里直接输入 `0.91`、回车后，实体立刻变化
2. 点击输入框外部关闭时，也会立刻应用
3. `角色比例 = 1.0` 时，角色外轮廓含边框刚好贴格子内边，不越界
4. 增大边框比例时，角色内部会略缩，但总外轮廓仍留在格子内
