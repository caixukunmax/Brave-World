# 修仙职业成长体系

> 版本：V0.1
> 状态：📝 策划文档 / 已确认基础框架
> 记录日期：2026-06-28

---

## 1. 设计目标

定义玩家从凡人踏入修仙之路后的长期成长主轴。当前版本聚焦**剑修方向**的最小可玩闭环，包含：

1. 玩家通过问答确定基础六维属性。
2. 玩家在剧情中面临**青云剑宗**邀请，可选择加入（宗教路径）或拒绝（散修路径）。
3. 两条路径提供差异化的剑修成长体验。

---

## 2. 已确认核心框架

### 2.1 入口与初始身份

- 玩家选择**寻仙**作为修仙方向。
- 初始称号为**寻仙客**，代表尚未择道的凡人修士。
- 玩家出生在**落叶庄**，一个凡人村庄，作为修仙旅程的起点。

### 2.2 初始职业方向

当前版本只实现**剑修**方向。法修、器修作为后续扩展方向，本文档中仅作占位说明。

| 方向 | 状态 | 说明 |
|------|------|------|
| 剑修 | **本期实现** | 近战/贴身/爆发，以剑诀与剑招为核心 |
| 法修 | 后续扩展 | 远程/读条/范围伤害 |
| 器修 | 后续扩展 | 法宝/傀儡/机关操控 |

---

## 3. 六维属性

创建角色时，通过 6 道选择题确定玩家基础六维。每道题对应一个维度，提供 3 个选项，不同选项加成不同。

| 维度 | 主要影响 | 与路径关联 |
|------|----------|------------|
| 根骨 | 气血、物理防御成长 | 高根骨更易被宗门认为"肉身可塑" |
| 悟性 | 功法学习速度、读条效率 | 高悟性宗门评价更高 |
| 心性 | 抗心魔、先手稳定性、宗教剧情判定 | **高心性更容易触发青云剑宗邀请** |
| 胆识 | 暴击率、先手伤害、危险探索 | 高胆识适合散修独行 |
| 机缘 | 掉落、奇遇、隐藏事件 | 高机缘散修奇遇更多 |
| 灵气亲和 | 法力上限、剑气/元素伤害 | 剑修里影响技能消耗与伤害 |

> **本期实现**：六维只影响基础属性成长和剧情触发判定，不引入额外战斗资源机制。

## 4. 剑修设计

### 4.1 定位

- **战斗距离**：近战/贴身为主。
- **核心风格**：高爆发、依赖走位贴近目标。
- **资源循环**：普攻与技能交替，通过连续命中维持输出节奏。

### 4.2 基础技能示例

| 技能 | 类型 | 效果 |
|------|------|------|
| 普通攻击 | 瞬发 | 造成 100% 物攻伤害 |
| 三连斩 | 瞬发 | 快速连续攻击 3 次，每次造成 80% 物攻伤害 |
| 破军势 | 瞬发 | 下一次攻击必暴击且伤害 +50% |

> 以上技能为示例，具体数值以战斗平衡文档为准。

## 5. 功法与职业限制

### 5.1 功法职业标签

每本功法拥有职业标签，决定哪些职业可以学习：

| 标签类型 | 说明 | 示例 |
|----------|------|------|
| 单职业 | 仅指定职业可学习 | 《青云剑诀》仅限青云剑宗教徒 |
| 多职业 | 指定多个职业可学习 | 《破军剑谱》剑修与散修剑士皆可学 |
| 全职业通用 | 所有职业皆可学习 | 《基础吐纳法》《轻身术》 |

### 5.2 本系限制

- 玩家只能学习与**本系**相关的功法。
- 本系由初始选择的职业方向决定：剑修只能学习剑系功法及相关通用功法。
- 法修、器修后续扩展后同样受此限制。

### 5.3 散修职业体系

- 散修拥有**独立的职业体系**，与宗门等级无关。
- 例如：剑修拒绝宗门后，可成为**散修剑士**，拥有散修专属职业等级与技能树。
- 宗门等级（外门/内门/真传）仅影响宗教路径；散修路径使用自己的职业评级（如：游侠→剑侠→剑魔/剑痴）。

## 6. 路径分化

### 6.1 触发方式

玩家完成早期主线区域后，在城镇/休息点触发**青云剑宗使者事件**：

- 使者根据玩家属性给出不同评价：
  - 心性高："小友心澄如镜，可愿入我青云剑宗？"
  - 根骨高："肉身根基扎实，适合练我宗门护体剑诀。"
  - 悟性高："悟性上佳，宗门剑谱可任你参悟。"
  - 属性均不高：不触发宗教邀请，默认进入散修路径。
- 玩家选择：
  - **同意** → 成为青云剑宗外门弟子，进入宗教路径。
  - **拒绝** → 与青云剑宗结仇（轻度），进入散修路径，获得"不羁"标签。

### 6.2 宗教路径：青云剑宗

| 维度 | 设计 |
|------|------|
| 职业树 | 单一宗门剑诀树，深度发展 |
| 剧情 | 宗门任务线为主，较线性 |
| 资源 | 宗门供给稳定，但功法选择受限 |
| 社交 | 师门关系、宗门声望 |
| 风险 | 叛宗代价大 |
| 战斗风格 | 招式正统、伤害稳定、有护体/剑阵类技能 |

### 6.3 散修路径

| 维度 | 设计 |
|------|------|
| 职业树 | 独立散修职业体系（如散修剑士），不依赖宗门等级 |
| 功法来源 | 奇遇、黑市、搜尸、寻宝、击杀野外精英怪 |
| 核心逻辑 | **投机与运气**，通过不确定途径获取资源 |
| 特色机制 | **变废为宝**：用残页、废料、低价材料合成或修复功法 |
| 剧情 | 自由探索、奇遇驱动 |
| 资源 | 靠掉落、交易，更自由 |
| 社交 | 独行侠或临时结盟 |
| 风险 | 缺少庇护，与青云剑宗轻度敌对 |
| 战斗风格 | 剑走偏锋、暴击/爆伤更高、生存能力较弱 |

## 7. 创建流程

```
创建角色
    ↓
选择"寻仙"方向
    ↓
获得称号：寻仙客
    ↓
选择初始职业方向：剑修（法修/器修后续扩展）
    ↓
六维问答（根骨/悟性/心性/胆识/机缘/灵气亲和）
    ↓
出生在落叶庄，完成新手引导与村庄主线
    ↓
离开落叶庄，完成早期主线区域
    ↓
触发青云剑宗使者事件
    ↓
    ├─ 同意 → 青云剑宗外门弟子（宗教路径）
    └─ 拒绝 → 散修，与青云剑宗轻度结仇
```

## 8. 本期明确不做

| 项目 | 说明 |
|------|------|
| 法修、器修 | 后续版本扩展 |
| 多个宗门 | 本期只实现青云剑宗 |
| 剑气/剑意等独立战斗资源 | 本期不引入，避免增加系统复杂度 |
| 重度阵营敌对 | 拒绝宗教只产生轻度敌对，不追杀、不禁入区域 |
| 正魔双线 | 本期先以"宗门/散修"二元分化为主，正魔倾向后续扩展 |
| 境界晋升 | 本期不实现境界突破玩法，专注职业路径分化 |
