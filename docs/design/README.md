# 系统设计文档（策划向）

本文档目录收录所有**玩法与策划相关**的设计文档，聚焦"玩家能做什么、游戏规则是什么、体验目标是什么"，**不涉及代码实现细节**。

代码实现、架构设计、重构方案、修复记录等技术文档，请移步 [`docs/tech/`](../tech/)。

> 规则：新增功能必须先有设计文档，经确认后方可进入代码实现。详见 [AGENTS.md](../../AGENTS.md)。
