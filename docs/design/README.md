## 🏷️ 状态标记规范

为保持文档状态一致性，design/ 下所有文档统一使用以下状态词：

| 状态 | 含义 | 适用场景 |
|------|------|----------|
| `待确认` | 方案尚未评审或定稿 | 初稿、讨论中 |
| `设计中` | 方案已评审，正在细化或等待开发 | 设计定稿后、开发前 |
| `已确认` | 方案已确认，可随时进入开发 | 设计完成、评审通过 |
| `实施中` | 正在编码实现 | 开发阶段 |
| `已实现` | 代码已合并，功能已上线 | 开发完成 |
| `已过时` | 方案已被新方案取代 | 历史归档 |

> 禁止使用的旧状态词：`进行中`、`技术设计阶段`、`待审阅`、`待开发`、`已完成`（请迁移到上表对应词）
