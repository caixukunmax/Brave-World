# 单位标签显示格式

## 1. 背景

当前玩家与野怪的第一行标签都带等级，但格式不一致：

- 玩家：`Lv.2 测试勇者`
- 野怪：`LV.2 野狼`

这会让同一套世界标签在视觉上不统一，也不利于后续继续收口标签规则。

## 2. 目标

统一所有核心战场单位第一行名字格式：

- 玩家：`LV.{level} {name}`
- 野怪：`LV.{level} {name}`

其中：

- `LV.` 使用全大写
- 等级与名字之间保留一个空格

## 3. 约束

### 3.1 玩家

玩家第一行标签和等级角标都使用同一套等级前缀：

- 第一行：`LV.{level} {name}`
- 等级角标模板：`LV.{level}`

### 3.2 野怪

野怪第一行继续绑定真实怪物等级与名称，格式固定为：

- `LV.{level} {name}`

## 4. 预期收益

- 玩家、野怪名字行风格统一
- 调试截图与战斗场景可读性更稳定
- 后续如果扩展 NPC 名字行，也有明确可复用格式
