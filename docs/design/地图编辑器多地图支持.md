# 地图编辑器多地图支持设计文档

> 版本：V1.0
> 状态：[实现中]
> 依赖：`MapDataManager`（已支持 GetMapList/CreateNewMap/Load/Save）、`GridManager.LoadMap`

---

## 1. 需求概述

当前地图编辑器（`MapEditor`）仅支持编辑当前加载的单张地图（`GridManager.CurrentMapName`）。策划需要能够在编辑器内：

1. **查看所有地图列表**
2. **切换地图**进行编辑
3. **创建新地图**
4. **删除地图**
5. **重命名地图**

---

## 2. 设计约束

- **不改动现有编辑核心逻辑**：框选、属性应用、撤销/重做、保存等保持不变。
- **地图数据存储格式不变**：仍使用 `res://maps/{mapName}/map.csv` + `config.cfg`。
- **即时切换**：切换地图时直接重新加载网格数据，清空当前选中和编辑历史（与进入编辑模式时行为一致）。
- **操作确认**：删除/重命名等破坏性操作需二次确认。

---

## 3. UI 设计

在 `MapEditor` 右侧编辑面板的顶部（诊断信息下方）新增「📁 地图管理」区域：

```
[修复版本 v4.5]
---
🗺️ 地图编辑器
---
📁 地图管理
[地图下拉 ▼       ] [切换]
[    新建地图    ] [删除] [重命名]
---
当前地图: 新手村
已选中: 0 个格子
...
```

### 3.1 控件说明

| 控件 | 类型 | 说明 |
|------|------|------|
| 地图下拉 | `OptionButton` | 显示 `MapDataManager.GetMapList()` 返回的所有地图名 |
| 切换 | `Button` | 加载选中的地图到编辑器 |
| 新建地图 | `Button` | 弹出新建地图对话框 |
| 删除 | `Button` | 删除当前在下拉中选中的地图（需二次确认） |
| 重命名 | `Button` | 弹出重命名对话框 |

### 3.2 新建地图对话框

```
┌────────────────────────────┐
│ 新建地图                    │
├────────────────────────────┤
│ 地图名称: [____________]   │
│ 宽度:     [____50_] 格    │
│ 高度:     [____50_] 格    │
├────────────────────────────┤
│ [      创建      ] [取消]  │
└────────────────────────────┘
```

- 名称校验：不允许为空、不允许与已有地图同名、不允许含特殊字符 `/\:*?"<>|`。
- 默认尺寸：50×50（与 `MapDataManager.CreateNewMap` 默认值一致）。

### 3.3 重命名对话框

```
┌────────────────────────────┐
│ 重命名地图                  │
├────────────────────────────┤
│ 原名称: 新手村              │
│ 新名称: [____________]     │
├────────────────────────────┤
│ [      确定      ] [取消]  │
└────────────────────────────┘
```

- 新名称校验同新建。
- 若重命名的是当前正在编辑的地图，切换后 `GridManager.CurrentMapName` 同步更新。

## 4. 服务端/数据层变更

### 4.1 MapDataManager 新增 API

```csharp
/// <summary>删除地图（删除文件夹及其内容）</summary>
public static Error DeleteMap(string mapName)

/// <summary>重命名地图（重命名文件夹，并保留内部文件）</summary>
public static Error RenameMap(string oldName, string newName)
```

**DeleteMap 流程：**
1. 构造路径 `res://maps/{mapName}/`
2. 递归删除文件夹内所有文件和子文件夹
3. 删除空文件夹

**RenameMap 流程：**
1. 校验 `oldName` 存在、`newName` 不存在
2. `DirAccess.Rename` 重命名文件夹
3. 若重命名的是当前加载的地图，调用方负责更新 `GridManager.CurrentMapName`

## 5. 客户端变更

### 5.1 MapEditor 新增逻辑

**地图管理区域初始化（`CreateEditorPanel`）：**
- 在「🗺️ 地图编辑器」标题下方插入 `📁 地图管理` 区域
- 初始化 `OptionButton` 时调用 `RefreshMapList()` 填充选项

**RefreshMapList：**
- 调用 `MapDataManager.GetMapList()`
- 按字母排序后填入 `OptionButton`
- 将当前 `GridManager.CurrentMapName` 设为选中项

**SwitchMap(string mapName)：**
1. 若 `mapName == GridManager.CurrentMapName`，直接返回
2. 调用 `GridManager.LoadMap(mapName)`
3. 清空 `SelectedCells`、撤销/重做栈、选择历史
4. 更新面板上的「当前地图」Label
5. `QueueRedraw()`

**CreateNewMap：**
1. 弹窗收集名称、宽、高
2. 校验名称合法性
3. `MapDataManager.CreateNewMap(name, width, height)`
4. 成功后刷新地图列表并自动切换到新地图

**DeleteMap：**
1. 获取下拉中选中的地图名
2. `ConfirmationDialog` 二次确认
3. `MapDataManager.DeleteMap(mapName)`
4. 若删除的是当前编辑的地图 → 切换列表中第一个可用地图（若无则自动创建默认地图）
5. 刷新列表

**RenameMap：**
1. 获取下拉中选中的地图名
2. 弹窗收集新名称
3. `MapDataManager.RenameMap(oldName, newName)`
4. 若重命名的是当前编辑的地图 → 更新 `GridManager.CurrentMapName`
5. 刷新列表

### 5.2 边界条件

| 场景 | 行为 |
|------|------|
| 删除当前正在编辑的地图 | 切换到列表中第一个地图；若列表为空，自动创建默认地图 `default_map` |
| 重命名当前正在编辑的地图 | 更新 `GridManager.CurrentMapName`，编辑器保持打开状态 |
| 新建同名地图 | 弹窗提示「地图已存在」，不创建 |
| 尝试删除唯一地图 | 弹窗提示「至少保留一张地图」，禁止删除 |
| 切换地图时有未保存的修改 | 直接切换（不提示保存；与现有退出编辑模式行为一致，保存靠手动点击「保存地图」） |
