# 技能图标系统设计

> 版本：v0.1
> 状态：已实现
> 范围：`clinetcsharp/Scripts/Skill*.cs`

## 1. 背景

当前客户端技能系统已经有：

1. 技能静态数据加载
2. 技能栏
3. 技能面板

但技能图标仍停留在“空边框占位”阶段，导致：

1. 技能栏辨识度弱
2. 技能面板扫描成本高
3. 后续 UI 继续扩展时无法复用统一图标语义

## 2. 目标

本轮目标不是引入一整套外部美术资源流水线，而是先补一套稳定、轻量、可复用的客户端技能图标系统。

要求：

1. 每个技能都有明确图标
2. 技能栏与技能面板共用同一套图标渲染
3. 不依赖临时截图或纯文字缩写充当图标
4. 后续替换成正式美术资源时，调用侧无需重写

## 3. 方案

### 3.1 图标抽象

引入两层抽象：

1. `SkillIconCatalog`
   - 负责按 `skillId` 返回图标视觉配置
   - 包括背景色、描边色、强调色、图形类型
2. `SkillIconView`
   - 负责把视觉配置绘制成真正的图标控件
   - 可嵌入技能栏、技能面板、未来的详情弹窗

### 3.2 当前阶段的图标风格

当前阶段采用“程序化绘制图标”：

1. 背景使用职业/属性倾向色
2. 中央图形用简单几何符号表达技能语义
3. 图标保持扁平、清晰、小尺寸可辨认

这样能避免：

1. 一次性补齐大量外部 PNG 资源
2. 图标资源路径、导入、热更链路同时变动
3. 后续 UI 重构时被静态资源结构反向绑死

## 4. 覆盖范围

当前至少覆盖这些客户端入口：

1. `SkillBar`
2. `SkillPanel`

后续若有：

1. 技能详情面板
2. 战斗浮层技能提示
3. GM / Debug 技能选择器

都优先复用 `SkillIconView`。

## 5. 非目标

本轮不做：

1. 正式美术风格重绘
2. 图标资源导出流水线
3. 图标动画特效
4. 稀有度边框系统
