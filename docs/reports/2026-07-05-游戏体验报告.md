# 2026-07-05 游戏体验报告（代码审查方式）

> 本次因 Godot 编辑器控制工具暂不可用，采用代码审查方式评估游戏体验。

## 1. UI/UX 面板系统

### PanelManager（面板管理器）
- **焦点管理**：`DraggablePanel` 子类通过 `Register/Unregister` 注册，同一时间仅一个面板获得焦点 ✅
- **层级管理**：获得焦点的面板自动提到最前（CanvasLayer 子节点末尾）✅
- **快捷键**：统一管理面板切换快捷键，避免冲突 ✅
- **场景兜底**：`[Export]` 绑定失败时按路径手动加载场景资源，健壮性良好 ✅

### DraggablePanel（可拖拽面板基类）
- **拖拽**：标题栏拖拽，支持 `IsAnyDragging` 全局标志避免与相机冲突 ✅
- **Resize**：8 方向调整大小，边缘检测区 `ResizeEdgeZone = 8px` ✅
- **最小化**：支持最小化/还原，高度记忆 ✅
- **位置保存**：防抖保存（`CancellationTokenSource` 去抖）✅
- **屏幕限制**：`ClampToScreen` 防止面板拖出视口 ✅

### 体验问题
1. **缺少面板位置记忆**：重启游戏后面板位置恢复为默认，频繁调整位置的玩家体验差
2. **缺少面板堆叠智能避让**：多个面板重叠时不会自动错开，需要手动调整
3. **面板最小尺寸固定**：`MinWidth = 300, MinHeight = 150`，在小屏幕上可能过大

## 2. 相机体验

### CameraController
- **平滑跟随**：`SmoothSpeed = 10.0f`，支持目标跟随 ✅
- **缓动曲线**：5 种缓动类型（Linear, SmoothStep, EaseOut, EaseIn, EaseInOut），可配置 `EasePower` ✅
- **拖拽延迟恢复**：松手后延迟 `ReturnDelay = 0.5s` 再恢复跟随，过渡自然 ✅
- **滚轮缩放**：`MinZoom = 0.2f, MaxZoom = 3.0f`，缩放速度 `0.1f` ✅
- **编辑模式**：支持自由视角和缩放限制校准 ✅

### 体验问题
1. **缩放中心问题**：代码中未看到以鼠标位置为中心的缩放实现，可能是以相机中心缩放，不符合现代地图操作习惯
2. **没有视野边界限制**：游戏地图应有边界，相机不应能无限拖到地图外（`Limit` 属性未使用）
3. **没有相机震动/特效接口**：战斗中的打击反馈需要相机震动，当前缺少此功能

## 3. 地图编辑器体验

### MapEditor（2600+ 行，单文件）
- **工具模式**：刷地形（Brush/BoxSelect）+ 放置装饰（PlaceDecoration）✅
- **选中系统**：框选（支持 Ctrl 多选/减选）、悬停提示 ✅
- **撤销历史**：差分命令模式，只记录修改格子的旧值，不深拷贝全网格 ✅
- **属性设置**：地形类型、装饰类型可配置 ✅
- **拖拽系统**：从调色板拖拽、移动已放置摆件 ✅
- **状态快照**：进入/退出编辑模式时保存/恢复游戏状态（玩家可见性、面板状态等）✅

### 体验问题
1. **🚨 性能杀手：69 处 GD.Print**：生产环境每帧可能触发大量日志写入，严重影响帧率。建议全部包裹为 `#if DEBUG`
2. **单文件过大**：2600+ 行，维护困难。建议拆分为：MapEditorCore（状态管理）、MapEditorInput（输入处理）、MapEditorUI（面板交互）、MapEditorHistory（撤销系统）
3. **缺少批量操作确认**：框选大量格子后刷地形没有"确认/取消"按钮，误操作难以恢复
4. **撤销Redo缺失**：代码中只看到 `UndoHistory`，没有看到 `RedoHistory`，用户只能撤销不能重做
5. **没有导出/导入功能**：编辑器地图数据无法导出为文件分享给其他开发者

## 4. 角色 UI（从设计文档评估）

### 2026-07-01 设计文档
- **执行状态 + 进度叠加**：浅色遮罩表示当前动作进度（施法、蓄力、普攻冷却）
- **大招就绪指示**：角色头像右上角绿色小圆点，亮起 = 可释放

### 评估
- 设计思路清晰，信息层次分明
- 建议补充：
  1. 冷却数字显示（精确到小数点后 1 位）
  2. 引导中 vs 冷却中的视觉区分（不同颜色遮罩）
  3. 绿色圆点呼吸动画（增强大招就绪的提示感）
  4. 多角色队伍时头像排列布局

## 5. 性能关注点

| 文件 | 行数 | 风险 |
|------|------|------|
| MapEditor.cs | 2600+ | 单文件过大，69 处 GD.Print |
| DebugPanel.cs | 拆分多文件 | 代码结构良好 |
| PanelManager.cs | 300+ | 适中 |
| CameraController.cs | 400+ | 适中 |

### 建议
1. **MapEditor.cs 拆分**：将 2600 行拆分为 4-5 个部分文件，每个负责一个子系统
2. **GD.Print 清理**：生产环境构建时移除所有调试日志（或包裹为 `#if DEBUG`）
3. **GridManager 渲染优化**：大地图时网格渲染可能消耗较大，考虑视口裁剪

## 6. 功能缺失（玩家会期望但还没有）

1. **设置/选项面板**：音量、画质、键位绑定、窗口模式等基础设置
2. **新手引导系统**：首次进入游戏时的操作提示
3. **音效/音乐控制**：背景音、音效开关和音量调节
4. **聊天系统**：玩家间交流的基础功能
5. **任务追踪 UI**：当前任务目标和进度显示
6. **小地图/大地图切换**：快速导航功能
7. **背包整理/筛选**：物品分类、快速整理按钮
8. **技能快捷键自定义**：F1-F12 或 1-9 键位绑定

3. 🟡 **中**：相机添加鼠标中心缩放和地图边界限制
4. 🟡 **中**：面板位置记忆持久化
5. 🟢 **低**：设置面板、新手引导、聊天系统等功能补充
